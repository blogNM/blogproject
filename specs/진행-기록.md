## 대화로 정한 것 (2026-10-08, 4단계 뒤)

- 사이트 이름 "Creat_"와 새 디자인 → [D-90](../docs/03-decisions/D-90-사이트-이름-Creat.md). 블로그 테마 틀 7가지 → [D-89](../docs/03-decisions/D-89-블로그-테마-틀.md).
- 테스트 계정 사진은 임시 그림 대신 저작권 걱정 없는 사진(Unsplash License 22장)을 씀 → [사진 출처](../docs/05-guides/사진-출처.md).
- 테스트 계정 수: 기능 확인은 역할별 10~15개(지금 10개), 큰 사이트 확인은 스크립트로 넣는 대량 데이터(회원 1,000·글 3만). 대량 데이터는 4단계 뒤 지금 한 번 하고, 스크립트를 남겨 5·6단계 뒤에 다시 돌림. 동시 접속 부하 테스트는 6단계 뒤 한 번 → [테스트 데이터](../docs/05-guides/테스트-데이터.md).
- [내 활동] 화면(쓴 글·좋아요 한 글·팔로잉·구독한 블로그), 목록마다 "다른 사람에게 보여주기" 체크, 기본 공개 → [D-91](../docs/03-decisions/D-91-내-활동-화면.md), 5단계에서 만듦.
- 진짜 홈페이지는 6단계 뒤에 염. 그 전에는 필요할 때 Cloudflare Tunnel로 잠깐 보여줌 → [배포 계획](../docs/05-guides/배포-계획.md).
- 관리자 계정·신고·블랙리스트는 아직 화면 없음. 신고 접수는 5단계, 처리·블랙리스트·관리자는 6단계 (지금 DB에는 테스트 관리자 2명과 예시 신고 5건만).

## 4단계: 댓글·좋아요·검색·피드 + 테마와 새 디자인 (2026-10-08)

**만든 것**

- 댓글·답글(`@닉네임`), 수정됨 표시, 삭제. 좋아요, 링크 복사, 조회수(하루 한 번).
- 통합 검색: 글·블로그·태그·닉네임 탭과 건수, 관련도·최신·인기순, 최근 검색어.
- 메인 피드: 최신·인기·팔로우·구독 탭, 메인 공지, 새로 생긴 블로그.
- 블로그 테마 틀 7가지(Odyssey, Poster, Whatever, Letter, Book Club, Magazine, Portfolio)와 강조 색·글꼴·머리 사진·문구, 저장 전 미리보기 (D-89, 사용자 요청).
- 사이트 이름 "Creat_" 워드마크와 새 디자인: 메인, 로그인·회원가입, 오류 화면(404·4xx·5xx), Pretendard 글꼴 (D-90, 사용자 요청).
- 테스트 데이터 `activity-4.py`: 블로그장 5명이 테마를 고르고 머리 사진·사진 글·댓글·좋아요·조회를 남김.

**확인한 것**

- 자동 테스트 122개 통과 (`CommentTest` 5, `BoardTest` 7, `ThemeTest` 3, 없는 화면 주소 1 추가).
- 브라우저(Playwright)로 메인·로그인·검색·글·블로그·관리·404 화면과 7개 테마 미리보기, 휴대폰 폭(390px) 확인. 콘솔 오류 없음(로그인 전 `/api/me` 401만).
- `activity-4.py` 44개 중 42개 성공. 2개는 정지된 서준의 댓글·좋아요가 막힌 것으로 맞는 동작.
- 대량 데이터(회원 1,000·블로그 83·글 3만·좋아요 7.6만·댓글 4.9만)에서 모든 화면 API가 0.4초 안. 메인 피드 최신 글 쿼리를 고쳐 0.39초 → 0.05초 (`bulk-data.py bench`).

**직접 확인할 곳**: [로컬-실행.md 7장](../docs/05-guides/로컬-실행.md#7-4단계-직접-확인하기), [테스트-데이터.md](../docs/05-guides/테스트-데이터.md)

**기본값으로 정하고 확인을 기다리는 것**

- #11 좋아요 1분 30번, 같은 사람의 좋아요 알림은 하루 한 번.
- #13 비회원 조회수는 IP 기준(IP는 해시값만 저장), 하루 한 번.
- #15 인기 글: 최근 7일 글 중 좋아요 많은 순, 같으면 조회수.
- 댓글 1분 10개, 최근 검색어 10개. 차단은 4단계에서 검색·피드에만 적용.

**다음 단계로 넘긴 것**: 팔로우·구독 버튼과 알림 화면(5단계), 차단한 사람의 댓글 막기(5단계), 테스트 계정용 실제 사진(맥에서 받기로 함).

## 3단계: 글쓰기·읽기 (2026-10-08)

**만든 것**

- 멤버가 Toast UI 에디터(마크다운)로 글쓰기, 수정, 삭제. 공지는 블로그장(또는 글 관리 권한이 있는 부블로그장)만.
- 블로그 화면 아래 글 목록: 공지, 최신순, 10·20·30개, 번호 페이지, 카테고리, 태그. 제목에 마우스를 올리면 첫 사진.
- 글 상세: 서버가 걸러 낸 본문, 카톡·X 미리보기(og 태그).
- 사진 올리기: jpg·png·gif·webp만, 확장자·MIME·파일 시그니처 모두 확인, 위치 정보(EXIF) 제거.
- 관리 화면의 카테고리 추가·이름 바꾸기·삭제.
- 쓰는 중인 글은 브라우저에 자동 저장.
- 테스트 데이터: 글 13개에 사진 5장, 카테고리, 태그가 보임.

**확인한 것**

- 자동 테스트 106개 통과 (`PostTest` 9, `PostListTest` 4, `ImageTest` 5, `OgTagTest` 3 추가).
- 브라우저(Playwright)로 테스트 계정 확인: `<script>`·`onerror`·`javascript:` 링크가 걸러짐, 블로그장은 남의 글을 못 고치고 지울 수 있음, 부블로그장(소연)은 삭제만 보임, 멤버(채림)는 남의 글에 버튼 없음, GPS가 든 사진을 올리면 위치 정보가 지워지고 방향은 남음, 임시 저장 불러오기, 일부 공개 블로그는 키로만.

**직접 확인할 곳**: [로컬-실행.md 6장](../docs/05-guides/로컬-실행.md#6-3단계-직접-확인하기), [테스트-데이터.md](../docs/05-guides/테스트-데이터.md)

**기본값으로 정하고 확인을 기다리는 것**

- #14 본문 1000자: 사진 문법 `![](주소)`을 뺀 마크다운 원문 글자 수 (추천안).
- 카테고리 이름 1~20자, 블로그 안에서 중복 불가.
- 본문에 바깥 사이트 사진 주소는 넣을 수 없음 (사이트에 올린 사진만).

**다음 단계로 넘긴 것**: 공감·댓글·조회수 세기(4단계), 내 글 삭제 알림 화면(5단계), 관리자 삭제·복구(6단계), 프로필·블로그 대표 사진 올리는 화면.

## 2단계: 계정 나머지 + 블로그 만들기·참여 (2026-10-08)

**만든 것**: 비밀번호 찾기, 이메일 찾기, 내 정보 수정, 회원탈퇴, 블로그 만들기(공개 3개·비공개 5개), 블로그 목록·검색, 참여 신청·승인·거절, 내 블로그, 블로그 나가기, 블로그 관리 화면, 테스트 데이터(회원 10명·블로그 5개).

**확인한 것**: 자동 테스트 85개 통과. 두 계정으로 만들기 → 신청 → 승인 → 내 블로그 흐름, 동시에 눌러도 개수 제한을 넘지 않음, 비밀번호를 바꾸면 이전 로그인이 끊김.

**기본값으로 정하고 확인을 기다리는 것**: #3 블로그 태그 5개, #6 인기순 = 구독자 수, #7 이름 30자·소개 200자, #8 나간 멤버는 바로 다시 신청. 새 질문: 비공개 블로그에 멤버가 들어오는 방법(지금은 신청 경로 없음, 블로그장 초대 제안).
