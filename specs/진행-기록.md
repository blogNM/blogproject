## 빠졌던 기능 채우기 (2026-10-08, 6단계 뒤)

**만든 것**: 요구사항을 다시 훑어 빠진 것을 채움. 메인 공지사항(관리자 쓰기·공지 화면·알림), 비공개 전환 알림(D-37), 로그인 연장 창(USR-03), 5초 요청 시간 제한(D-48), 블로그 태그 검색(BLG-03), 블로그 안 회원 신고(D-85), 블로그 만들 때 대표 이미지(BLG-01), 블로그 알림 일괄 삭제(6.7). 사용자 요청으로 글 화면 [목록] 버튼과 휴대폰 공유 창.

**확인한 것**: 자동 테스트 153개 통과 (`NoticeTest` 1, `BlogExtrasTest` 3 추가). 브라우저로 관리자 공지 쓰기 → 메인 공지 → 본문(마크다운이 걸러진 HTML), 블로그 만들기 대표 이미지 칸, 글 [목록]이 블로그 글 목록으로 돌아감, 390px 너비에서 옆으로 넘치지 않음.

**아직 남긴 것**: D-83 IP별 요청 제한 수치, 비공개 블로그 초대, 카카오톡 전용 공유(카카오 앱 키 필요).

## 5단계: 팔로우·구독·프로필·차단·신고·알림 (2026-10-08)

**만든 것**

- 회원 팔로우·블로그 구독(켜기·끄기), 받는 사람에게 하루 한 번 알림.
- 프로필 `/members/{번호}`: 사진·소개·운영·참여 블로그·팔로워·팔로잉. 본인이 보면 [내 활동]이 되어 쓴 글·좋아요 한 글·팔로잉·팔로워·구독한 블로그를 보고, 목록마다 "다른 사람에게 보여주기"를 고름(기본 공개, D-91).
- 차단: 양방향으로 글·댓글을 숨기고 팔로우를 풀며 댓글·좋아요·참여 신청을 막음. 같은 블로그 멤버끼리는 그 블로그 안에서 보임.
- 신고 접수: 회원·블로그·글·댓글, 사유 6가지, 같은 대상 2주에 한 번. 블로그장이 대상이거나 블로그·프로필 신고면 관리자 접수.
- 알림: 종 아이콘(30초마다), 탭 사이드바, 읽음·모두 읽음·전체 삭제, 내 정보에서 종류별 켜기·끄기와 보관 30일·7일, 블로그장은 블로그 알림 보관. 매일 04:00 정리.
- 내 정보: 프로필 사진·소개(150자), 알림 설정, 차단한 회원.
- 글쓰기: 글자 색 7가지(D-93), 기울임이 사파리에서도 비스듬히 보이게 고침(사용자 요청).
- 테스트 데이터 `activity-5.py`.

**확인한 것**

- 자동 테스트 133개 통과 (`SocialTest` 10, 글자 색 1 추가).
- 브라우저(Playwright)로 프로필·내 활동·신고 창·종 알림 사이드바·블로그 구독 버튼·글자 색 버튼 확인. 콘솔 오류 없음(로그인 화면의 `/api/me` 401만).

- 글 상세: 서버가 걸러 낸 본문, 카톡·X 미리보기(og 태그).

- 관리 화면의 카테고리 추가·이름 바꾸기·삭제.
- 쓰는 중인 글은 브라우저에 자동 저장.

**확인한 것**
