# Creat_ v1.1.0 업데이트 소식

이제 구글 계정으로 로그인할 수 있어요.

## 바뀐 점

### 구글로 로그인

로그인 화면의 **구글로 로그인** 버튼을 누르고 구글 계정을 고르면 바로 로그인돼요.

- 구글 계정과 같은 이메일로 이미 가입했다면, 그 계정으로 그대로 로그인돼요. 쓰던 블로그와 글도 그대로예요.
- 처음이라면 닉네임을 정하고 약관에 동의하면 가입이 끝나요. 이메일 인증번호는 받지 않아도 돼요.

![구글로 로그인 버튼](/img/releases/v1.1.0/google-login.png)

구글로 가입한 계정은 비밀번호가 없어요. 비밀번호가 필요하면 로그인 화면의 **비밀번호를 잊었어요**에서 새로 만들 수 있어요.
