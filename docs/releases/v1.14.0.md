# Creat_ v1.14.0 업데이트 소식

글과 댓글에 쓴 **욕설을 자동으로 가려요.**

> 저장은 그대로 되고, 욕설만 <span class="hl-yellow">\*\*</span>처럼 별표로 바뀌어요.

## 욕설을 자동으로 걸러요

**무엇이 바뀌었나요**

- 글 제목·본문과 댓글에 욕설이 있으면 저장할 때 글자 수만큼 별표(\*)로 가려져요. 글은 그대로 올라가요.
- 글자 사이에 숫자나 기호를 넣어도(시1발, 시.발) 찾아서 가려요.
- 욕설이 든 **닉네임**과 **태그**는 쓸 수 없어요. 가입하거나 닉네임을 바꿀 때, 태그를 달 때 알려 드려요.
- 링크와 사진 주소는 건드리지 않아요.

**이미 쓴 글은요?**

이미 올라간 글과 댓글은 그대로예요. 고쳐서 다시 저장하면 그때 걸러져요.
