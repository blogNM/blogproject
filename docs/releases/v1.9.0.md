# Creat_ v1.9.0 업데이트 소식

위쪽 메뉴 오른쪽 끝에 **내 프로필 사진**이 보여요. 로그인 화면에서도 <u>다크모드를 켜고 끌 수</u> 있어요.

> 위쪽의 <span class="hl-yellow">내 사진을 누르면</span> 내 블로그, 내 정보, 로그아웃 메뉴가 열려요.

![고친 뒤: 위쪽 메뉴 오른쪽 끝의 내 사진과, 누르면 열리는 메뉴](/img/releases/v1.9.0/header-after.png)

## 위쪽 메뉴에 내 사진이 보여요

**무엇이 불편했나요**

로그인하면 위쪽 메뉴에 "내 블로그 · 내 활동 · OO님 · 로그아웃"이 글자로 늘어서 있었어요. 내 프로필 사진은 이름을 눌러 들어가야 볼 수 있었어요.

![고치기 전: 글자 링크만 늘어선 위쪽 메뉴](/img/releases/v1.9.0/header-before.png)

**어떻게 고쳤나요**

- 위쪽 메뉴를 **검색 · 알림 · 다크모드 · 내 사진** 네 개로 줄였어요.
- **내 사진을 누르면** 메뉴가 열려요. 맨 위의 사진과 이름을 누르면 내 활동으로 가고, 그 아래에 내 블로그, 내 정보, 로그아웃이 있어요.
- 메뉴 바깥을 누르거나 Esc를 누르면 닫혀요.
- 사진을 아직 안 올렸다면 **닉네임 첫 글자**가 동그라미에 보여요.
- 내 정보에서 사진이나 닉네임을 바꾸면 위쪽 메뉴도 **바로** 바뀌어요.

**얼마나 달라졌나요**

> 위쪽 메뉴 <u>7개 → 4개</u>. 휴대폰에서도 한 줄에 다 들어가요.

## 로그인 화면에서도 다크모드를 켜요

**무엇이 불편했나요**

로그인·가입 화면에는 위쪽 메뉴가 없어서 다크모드 버튼이 없었어요.

![고치기 전: 로그인 화면에 다크모드 버튼이 없어요](/img/releases/v1.9.0/login-before.png)

**어떻게 고쳤나요**

- 로그인·가입 화면 **오른쪽 위에 달·해 버튼**을 달았어요. 누르면 바로 어두워지고, 고른 값은 다른 화면에도 그대로 이어져요.

![고친 뒤: 오른쪽 위의 달 버튼](/img/releases/v1.9.0/login-after.png)

![다크모드를 켠 로그인 화면](/img/releases/v1.9.0/login-dark.png)
