# Creat_ v1.0.1 업데이트 소식

가입이 더 잘 되도록 고치고, 공지사항을 알아보기 쉽게 바꿨어요.

## 고친 점

- **인증번호 메일**: 회원가입 때 인증번호 메일이 오지 않던 문제를 고쳤어요. 받지 못하셨던 분은 다시 시도해 주세요.

## 바뀐 점

### 공지사항에 카테고리가 붙어요

공지사항 목록과 메인 화면에서 글마다 **공지**, **업데이트** 표시가 보여요. 업데이트는 이런 버전 소식이에요.

![공지사항 카테고리](/img/releases/v1.0.1/notice-category.png)

### 한 이메일에 한 계정, 가입 화면에서 바로 안내

Creat_ 는 한 이메일로 한 계정만 만들 수 있어요. 이제 가입 화면의 이메일 칸 바로 아래에 이 안내가 보여요.

이미 가입된 이메일로 인증번호를 받으려 하면, 인증번호 대신 "이미 가입된 이메일입니다" 메일이 가요. 다른 사람이 내 이메일로 가입했는지 엿볼 수 없도록 화면에는 따로 표시하지 않아요.

![가입 화면 이메일 안내](/img/releases/v1.0.1/signup-email.png)

계정이 기억나지 않으면 로그인 화면의 **이메일 찾기**, **비밀번호 찾기**를 써 주세요.
