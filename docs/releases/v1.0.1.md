# Creat_ v1.0.1 업데이트 소식

가입이 더 잘 되도록 고치고, 공지사항을 알아보기 쉽게 바꿨어요.

## 고친 점

- **인증번호 메일**: 회원가입 때 인증번호 메일이 오지 않던 문제를 고쳤어요. 받지 못하셨던 분은 다시 시도해 주세요.

## 바뀐 점

### 공지사항에 카테고리가 붙어요

공지사항 목록 위에 **전체 · 일반 · 업데이트 · 수정 · 점검** 탭이 생겨서, 보고 싶은 종류만 골라 볼 수 있어요. 목록과 메인 화면에서도 글마다 카테고리 표시가 붙어요. 업데이트는 이런 버전 소식이에요.

![공지사항 카테고리](/img/releases/v1.0.1/notice-category.png)

### 가입 화면에 이메일 중복 확인 버튼

Creat_ 는 한 이메일로 한 계정만 만들 수 있어요. 이제 가입 화면에서 이메일을 넣고 **중복 확인**을 누르면, 이미 가입된 이메일인지 바로 알려 드려요. 가입할 수 있는 이메일일 때만 인증번호를 받을 수 있어요.

![가입 화면 이메일 중복 확인](/img/releases/v1.0.1/signup-email.png)

이미 가입된 이메일이라면 로그인 화면의 **이메일 찾기**, **비밀번호 찾기**를 써 주세요.
