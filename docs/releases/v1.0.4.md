# Creat_ v1.0.4 업데이트 소식

블로그를 만들 때부터 원하는 모양으로 꾸미고, 여러 블로그에 속해 있어도 한 곳에서 글을 쓸 수 있어요.

## 바뀐 점

### 블로그를 만들 때 테마를 골라요

블로그 만들기 화면에서 테마 틀 7가지 중 하나를 고르고, 강조 색, 글꼴, 머리 사진 위 문구, 머리 사진까지 한 번에 정할 수 있어요. 만든 뒤에도 블로그 관리에서 언제든 다시 꾸밀 수 있어요.

### 첫 화면에 [글 작성하기] 버튼

블로그를 만들었거나 다른 블로그에 참여했다면, 메인 첫 화면의 [블로그 만들기] 옆에 **글 작성하기** 버튼이 생겨요.

### 어느 블로그에 쓸지 골라요

[글 작성하기]를 누르면 글쓰기 화면 맨 위에서 내가 속한 블로그 중 하나를 고를 수 있어요. 고른 블로그에 글이 올라가요. 쓰는 중에 블로그를 바꿔도 쓰던 글은 그대로 남아요.
