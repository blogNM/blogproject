# Creat_ v1.5.0 업데이트 소식

글쓰기에 **체크박스 목록**이 생겼어요. 그리고 글자를 크게 해도 <u>더 이상 저절로 굵어지지 않아요.</u>

> 준비물·할 일은 <span class="hl-yellow">체크박스 목록</span>으로, 설명은 글머리 기호 목록으로 정리해 보세요. 글자 크기와 굵게는 이제 따로 골라요.

![글쓰기 편집기의 글머리 기호 목록·체크박스 목록·큰 글자 (예시 글)](/img/releases/v1.5.0/lists-edit.png)

## 글자를 크게 하면 굵게까지 바뀌었어요

**무엇이 불편했나요**

글자 크기에서 "아주 크게"를 고르면 글자가 커지면서 **굵게도 함께** 바뀌었어요. 크기만 키우고 굵기는 그대로 두고 싶어도 그럴 수 없었어요.

**원인**

"아주 크게" 모양에 굵게가 함께 들어 있었어요. 굵게는 [B] 버튼으로 따로 고를 수 있는데, 크기가 굵기까지 정해 버린 거예요.

**어떻게 고쳤나요**

- 글자 크기(작게·크게·아주 크게)는 이제 **크기만** 바꿔요.
- 굵게 하고 싶으면 [B] 버튼을 함께 누르면 돼요.
- 이미 "아주 크게"로 쓴 글은 보통 굵기로 보여요. 굵게 보이길 원하면 글을 고쳐 [B]를 눌러 주세요.

**얼마나 달라졌나요**

> <span class="ts-xlarge">아주 크게</span>를 골라도 글자 굵기는 그대로예요. 크기와 굵기를 <u>따로따로</u> 고를 수 있어요.

## 체크박스 목록이 생겼어요

**무엇이 불편했나요**

준비물이나 할 일처럼 "했다/안 했다"를 보여 주고 싶은 목록을 쓸 방법이 없었어요. 글머리 기호 목록에 "(완료)"를 붙여 쓰거나 ☑ 같은 글자를 찾아 넣어야 했어요.

**원인**

글쓰기 도구에 목록이 글머리 기호 목록과 번호 목록 두 가지뿐이었어요.

**어떻게 고쳤나요**

- 도구 막대의 목록 칸이 **글머리 기호 목록 · 번호 목록 · 체크박스 목록** 세 개가 됐어요. 회원 글쓰기와 공지 쓰기 모두 같아요.
- 쓰는 칸에서 네모를 누르면 체크하고, 다시 누르면 풀려요.
- 글을 읽는 사람에게는 체크한 그대로 보여요. 읽는 사람이 눌러서 바꿀 수는 없어요.
- 네모 표시는 글자 수(1000자)에 넣지 않아요. 글머리 기호 목록과 똑같이 세요.

**얼마나 달라졌나요**

> 할 일·준비물·확인 목록을 <span class="hl-yellow">한눈에 보이게</span> 정리할 수 있어요.
