# Creat_ v1.4.0 업데이트 소식

이제 네이버와 카카오 계정으로도 Creat_에 로그인할 수 있어요.

## 바뀐 점

### 네이버·카카오로 로그인

로그인 화면의 구글 버튼 아래에 **네이버로 로그인**, **카카오로 로그인** 버튼이 생겼어요.

![로그인 화면의 구글·네이버·카카오 로그인 버튼](/img/releases/v1.4.0/social-buttons.png)

- 이미 같은 이메일로 가입한 회원이면 그 계정에 바로 연결되어 로그인돼요.
- 처음 오셨다면 닉네임과 약관 동의만 하면 가입이 끝나요. 비밀번호를 따로 만들 필요가 없어요.
- 네이버·카카오에서 이메일 제공에 동의해야 가입할 수 있어요. 동의하지 않으면 로그인 화면에서 알려 드려요.
- 탈퇴하면 연결도 함께 끊겨서, 같은 계정으로 다시 가입할 수 있어요.

![새 로그인 화면](/img/releases/v1.4.0/social-login.png)

### 회원가입 안내

회원가입에서 이메일을 확인할 때, 네이버나 카카오로 가입된 이메일이면 "네이버 계정으로 가입된 이메일입니다"처럼 어느 계정으로 로그인하면 되는지 알려 드려요.

### 다른 카카오·구글 계정으로 로그인하기

**무엇이 불편했나요**

로그아웃한 뒤 [카카오로 로그인]을 다시 누르면, 고를 틈도 없이 <u>예전에 쓴 카카오 계정으로 바로 로그인</u>됐어요. 가족과 같은 컴퓨터를 쓰거나 계정이 여러 개라면 다른 계정으로 들어갈 방법이 없었어요.

**원인**

카카오(그리고 구글)는 한 번 로그인한 계정을 기억해 두고, 따로 묻지 않으면 그 계정으로 바로 넘겨줘요. Creat_가 "계정을 골라 주세요"라고 요청하지 않고 있었어요.

**어떻게 고쳤나요**

이제 카카오·구글로 로그인할 때마다 **어느 계정으로 로그인할지 고르는 화면**이 나와요. 거기서 다른 계정을 고르거나 새 계정을 더할 수 있어요.

![카카오로 로그인을 누르면 계정을 고르는 화면이 나오는 순서 (안내 그림)](/img/releases/v1.4.0/kakao-select-account.png)

**얼마나 달라졌나요**

> 예전: 로그아웃해도 늘 같은 카카오 계정으로 로그인 → 이제: <span class="hl-yellow">누를 때마다 계정을 고를 수 있어요.</span>

네이버는 계정 고르기 화면을 제공하지 않아 예전과 같아요. 다른 네이버 계정으로 로그인하려면 naver.com에서 로그아웃한 뒤 다시 [네이버로 로그인]을 눌러 주세요.

## 운영 메모

- 네이버(D-107)·카카오(D-108) 로그인은 Spring Security OAuth2 Client로 받고, 구글과 같은 JWT 쿠키를 내려줘요. 테이블 변경은 없어요.
- 시크릿: `NAVER_CLIENT_ID`·`NAVER_CLIENT_SECRET`, `KAKAO_CLIENT_ID`(REST API 키)·`KAKAO_CLIENT_SECRET`. 값이 없으면 그 버튼은 숨겨져요.
- Callback/Redirect URI: `https://creat.java21.net/login/oauth2/code/naver`, `https://creat.java21.net/login/oauth2/code/kakao`
- 카카오는 `account_email`만 요청하고, 유효·인증된 이메일일 때만 가입·연결해요. 이메일을 필수 동의로 받으려면 비즈 앱이어야 해요.
- 계정 고르기: 카카오·구글 로그인 요청(`/oauth2/authorization/kakao|google`)에 `prompt=select_account`를 붙임. `SelectAccountRequestResolver`가 스프링 `DefaultOAuth2AuthorizationRequestResolver`(state·PKCE·nonce)를 감싸 `kakao`·`google` 등록에만 더하고, `SecurityConfig`의 `oauth2Login().authorizationEndpoint().authorizationRequestResolver(...)`로 연결. 네이버(`/oauth2/authorization/naver`)는 그대로. 계정 고르기 그림은 실제 카카오 화면이 아니라 안내 그림이에요 (D-108 후속).
- 네이버 앱이 "개발 중"이면 등록한 테스트 아이디만 로그인돼요. 모두에게 열려면 검수가 필요해요.

자세한 내용은 [D-107](docs/03-decisions/D-107-네이버-로그인.md), [D-108](docs/03-decisions/D-108-카카오-로그인.md), [CHANGELOG](CHANGELOG.md)에 있어요.
