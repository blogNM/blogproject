# Creat_ v1.11.1 업데이트 소식

로그인할 때 나오는 **로봇 확인 상자**가 Google reCAPTCHA로 바뀌었어요.

> 비밀번호를 여러 번 틀리면 <span class="hl-yellow">"로봇이 아닙니다" 상자</span>가 나와요. 상자를 눌러 확인한 뒤 다시 로그인하면 돼요.

## 로봇 확인 상자가 바뀌었어요

**무엇이 바뀌었나요**

- 로봇 확인 상자가 Cloudflare에서 **Google reCAPTCHA**("로봇이 아닙니다" 체크박스)로 바뀌었어요.
- 상자가 나오는 때는 그대로예요. 같은 계정으로 **3번** 틀리면 상자가 나오고, **5번** 틀리면 5분 동안 로그인할 수 없어요. 같은 곳에서 계정을 바꿔 가며 1시간에 5번 틀려도 상자가 나와요.
- 관리자 로그인도 같아요.
- 다크모드에서는 상자도 어두운 모양으로 나와요.

**왜 바꿨나요**

Google 계정 하나로 관리할 수 있는 확인 방식으로 모았어요.

## 운영 메모

| 항목 | 내용 |
|---|---|
| 결정 | [D-118](docs/03-decisions/D-118-reCAPTCHA로-바꿈.md) |
| 키 | GitHub Actions secrets `RECAPTCHA_SITE_KEY`·`RECAPTCHA_SECRET_KEY` (v2 체크박스 키). `RECAPTCHA_ID`·`RECAPTCHA_PASSWORD` 등 다른 이름도 읽음. 만드는 법은 [도커-배포.md](docs/05-guides/도커-배포.md#로봇-확인-실제-키-넣기-d-118) |
| 서버 | `CaptchaVerifier` → `https://www.google.com/recaptcha/api/siteverify`. 테스트 키로 뜨면 시작할 때 로그 경고 |
| CSP | reCAPTCHA 주소만 열고 Cloudflare는 뺌. 회원·관리자 로그인 화면은 인라인 style 허용 |
| API | `captchaToken`(요청), `captchaSiteKey`(응답) |

- 캡처 없음: 작업 환경에서 Google reCAPTCHA에 닿지 않아 실제 상자를 찍지 못했어요.
