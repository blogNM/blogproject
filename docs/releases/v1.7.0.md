# Creat_ v1.7.0 업데이트 소식

내 블로그에 **블로그 통계**가 생겼어요. 오늘 몇 명이 왔는지, 어느 시간에 많이 보는지, <u>어디서 어떤 검색어로 들어왔는지</u> 한눈에 볼 수 있어요.

> 블로그 홈의 [통계] 버튼을 눌러 보세요. <span class="hl-yellow">시간별·일별·월별 방문자와 조회수</span>, 들어온 경로, 검색어, 많이 본 글이 한 화면에 있어요.

![블로그 통계: 오늘·어제·최근 30일·전체 방문자와 일별 그래프 (예시 블로그)](/img/releases/v1.7.0/stats-day.png)

## 내 블로그에 누가 얼마나 오는지 알 수 없었어요

**무엇이 불편했나요**

글마다 조회수만 보였어요. 블로그 전체에 하루 몇 명이 왔는지, 지난달보다 늘었는지, 몇 시에 많이 보는지 알 방법이 없었어요.

**원인**

조회수를 글마다 하나의 숫자로만 쌓고 있었어요. 언제 봤는지는 남기지 않아서 날짜·시간별로 나눠 볼 수 없었어요.

**어떻게 고쳤나요**

- 블로그 홈이나 글을 열면 **언제 열었는지** 한 줄씩 남겨요.
- 블로그 관리 화면 맨 위에 **블로그 통계**를 두었어요. 블로그 홈에서는 블로그장·부블로그장에게 [블로그 관리] 옆 **[통계]** 버튼이 보여요.
- 맨 위 네 칸: **오늘 · 어제 · 최근 30일 · 전체** 방문자와 조회수
- 그래프는 **[시간별]**(고른 날 0~23시) · **[일별]**(최근 7·14·30·90일) · **[월별]**(최근 12달)로 바꿔 볼 수 있어요. 막대는 방문자, 선은 조회수예요. 막대에 마우스를 올리거나 손가락으로 누르면 그날 숫자가 보이고, [표로 보기]를 누르면 숫자 표로도 봐요.
- **방문자**는 하루에 한 사람을 한 번으로 세요. **조회수**는 블로그 홈과 글을 연 횟수예요.
- 이렇게는 세지 않아요: 블로그를 함께 쓰는 **멤버가 본 것**, 같은 화면을 **30분 안에 다시 연 것**(새로 고침), **검색 로봇**.

![시간별: 점심과 저녁에 많이 와요 (예시 블로그)](/img/releases/v1.7.0/stats-hour.png)

![월별: 최근 12달 동안 방문자가 늘어난 모습 (예시 블로그)](/img/releases/v1.7.0/stats-month.png)

**얼마나 달라졌나요**

> 글 조회수 숫자 하나 → <span class="hl-yellow">시간별·일별·월별 그래프와 표</span>. 어느 요일·시간에 글을 올리면 좋을지 <u>숫자로 보고 정할 수 있어요.</u>

## 어디서 들어왔는지 알 수 없었어요

**무엇이 불편했나요**

손님이 Creat_ 검색으로 왔는지, 피드나 인기 글에서 왔는지, 댓글을 보고 들어왔는지 몰랐어요. 어떤 검색어로 찾아왔는지도 알 수 없었어요.

**원인**

블로그로 들어오는 링크가 모두 같은 주소라서, 어느 화면에서 눌렀는지 구분할 표시가 없었어요.

**어떻게 고쳤나요**

- Creat_ 안에서 블로그·글로 가는 링크에 **어디서 눌렀는지** 표시를 붙였어요. 블로그가 열리면 그 표시를 읽어 남기고, 주소창에서는 바로 지워요(주소를 복사해 나눠도 깔끔해요).
- 이렇게 나눠 보여요:

  | 들어온 경로 | 이런 때 |
  |---|---|
  | Creat_ 검색 | 검색 결과에서 눌렀을 때. **검색어**도 함께 |
  | 피드 최신 글 · 피드 인기 글 · 팔로우 피드 · 구독 피드 | 메인 피드 탭마다 따로 |
  | 블로그 둘러보기 · 새로 생긴 블로그 | 메인의 블로그 카드, 새로 생긴 블로그 목록 |
  | 댓글 보고 회원 눌러서 | 다른 글의 댓글에서 내 이름을 누르고 → 내 프로필에서 블로그로 왔을 때 |
  | 회원 프로필·활동 · 알림 | 프로필, 알림을 눌러 왔을 때 |
  | 다른 사이트 | 네이버·구글·인스타그램 등. **사이트 이름**과, 주소에 실려 오면 검색어도 |
  | 직접 들어옴 | 주소를 직접 쳤거나 즐겨찾기·메신저 링크로 왔을 때 |

- 블로그 홈에서 글로 옮겨 가는 것처럼 **블로그 안에서 옮겨 다닌 것**은 들어온 경로에서 빼고 따로 개수만 알려 줘요.
- 경로·검색어·다른 사이트·많이 본 글은 위에서 고른 기간(시간별·일별·월별)을 따라 바뀌어요.

**얼마나 달라졌나요**

> 손님이 <span class="hl-yellow">어디서, 어떤 검색어로</span> 왔는지 비율 막대와 순위로 보여요. 검색어 순위를 보고 <u>글 제목·태그를 정할 때</u> 써 보세요.

![들어온 경로·검색어·다른 사이트·많이 본 글 (예시 블로그, 최근 12달)](/img/releases/v1.7.0/stats-sources.png)

![휴대폰에서 본 블로그 통계](/img/releases/v1.7.0/stats-mobile.png)

## 개인정보는 이렇게 지켜요

- 방문한 사람의 **IP 주소는 저장하지 않아요.** 하루마다 바뀌는 암호 같은 값만 남겨서, 누가 왔는지 알 수 없고 다른 날 기록끼리 이어 볼 수도 없어요.
- 통계는 **블로그장·부블로그장만** 볼 수 있어요. 일반 멤버·다른 회원·비회원에게는 보이지 않아요.
- 기록은 **400일** 동안 두고, 지나면 새벽에 저절로 지워요.

## 운영 메모

| 항목 | 내용 |
|---|---|
| 저장 | Flyway V15 `blog_visits(blog_id, post_id, visited_at, visitor_hash, source, ref_host, keyword)`, 인덱스 `(blog_id, visited_at)`·`(visitor_hash, blog_id, visited_at)`·`(visited_at)`. 외래 키 없음(폐쇄 블로그 완전 삭제 때 함께 지움) |
| 기록 | `POST /api/blogs/{slug}/visits` (비회원 허용, CSRF는 `api.js`), 늘 204. `VisitService`: 로봇 UA·UA 없음·볼 수 없는 블로그·그 블로그 멤버·다른 블로그 글·`repeat-window`(30m) 안 같은 화면은 건너뜀 |
| 방문자 값 | `HMAC-SHA256(CODE_HASH_SECRET, "VISIT:" + 날짜 + ":" + IP + ":" + UA)`. IP 원문 없음, 날마다 바뀜 |
| 경로 | `js/visit.js`의 `withFrom()`으로 링크에 `?from=`(검색은 `&q=`), `recordVisit()`이 `from`·`q`·`document.referrer`를 보내고 `history.replaceState`로 지움. 서버 `VisitSource.classify()`가 표시 → 같은 사이트 referrer(`/blog/{slug}` = inside, `/search.html?q=` = search, `/members/` = profile, 그 밖 site) → 다른 사이트(호스트, `q`·`query`·`wd`·`search_query`·`keyword`) → direct |
| 통계 | `GET /api/blogs/{slug}/stats?unit=hour&date=` · `unit=day&from=&to=`(최대 92일) · `unit=month&months=`(1~24, 기본 12). `@blogAuth.canViewStats`(OWNER·SUB_OWNER). 방문자 = `COUNT(DISTINCT visitor_hash)`(값이 날마다 바뀌어 기간 합계는 날마다 센 방문자의 합) |
| 화면 | `blog-manage.html` `#stats`, `js/pages/blog-stats.js`(SVG 막대+선, 툴팁, 표, ResizeObserver). 글자는 모두 `textContent` |
| 정리 | `VisitCleanupJob` 매일 04:20, 5,000줄씩, ShedLock `visitCleanup`, `APP_JOBS_ENABLED`(app-a) |
| 설정 | `BLOG_STATS_RETENTION_DAYS`=400, `BLOG_STATS_REPEAT_WINDOW`=30m, `BLOG_STATS_KEYWORD_MAX`=30, `BLOG_STATS_MAX_DAY_RANGE`=92, `BLOG_STATS_TOP_COUNT`=10 |

- 서버 메모리에 아무것도 두지 않아 두 앱(8341·8342) 어느 쪽이 받아도 같음 (SCL-01, D-111).
- 글마다 보이는 조회수(D-77, 멤버 포함·하루 한 번)는 그대로 두고 블로그 통계는 따로 셈. 두 숫자는 다를 수 있음.
- 다른 사이트 검색어: 구글 등은 주소에서 검색어를 지워 보내 대부분 남지 않음. 글 본문 속 링크는 `noreferrer`라 "직접 들어옴"으로 셈.
- 캡처: 로컬(`local` 프로필) 테스트 데이터의 "서울 맛집 탐방" 블로그에 약 11달 치 예시 방문 기록을 SQL로 넣고, 비회원 브라우저로 블로그 둘러보기·검색(국밥)·새로 생긴 블로그·댓글 쓴 사람 → 프로필 → 블로그·네이버 referrer를 직접 눌러 explore·search(검색어 국밥)·new·comment·external(search.naver.com, 을지로 국밥)·inside가 남고 주소창에서 `from`이 지워지는 것을 확인. 헤드리스 브라우저 기본 UA는 세지 않음.
- 테스트: `StatsTest` 6개(세는 방문·안 세는 방문, 30분, 경로 15가지, 시간별·일별·월별 합계, 볼 수 있는 사람, 보관 기간), `HealthTest` 정리 작업 5개.

자세한 내용은 [D-112](docs/03-decisions/D-112-블로그-통계.md), [CHANGELOG](CHANGELOG.md)에 있어요.
