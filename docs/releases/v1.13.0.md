# Creat_ v1.13.0 업데이트 소식

보고 싶지 않은 회원이나 블로그를 **관심 없음**으로 숨길 수 있어요.

> 피드에서 글 카드 오른쪽 위 <span class="hl-yellow">⋮ 버튼</span>을 누르면 바로 숨길 수 있어요.

![피드 글 카드의 ⋮ 메뉴: 이 회원 관심 없음, 이 블로그 관심 없음](/img/releases/v1.13.0/card-menu.png)

## 관심 없는 회원·블로그를 숨겨요

**무엇이 바뀌었나요**

- 메인 피드와 검색 결과의 글 카드에 **⋮ 메뉴**가 생겼어요. "이 회원 관심 없음", "이 블로그 관심 없음"을 고르면 그 글들이 바로 사라져요.
- 회원 프로필과 블로그 홈에도 **[관심 없음]** 버튼이 있어요. 한 번 더 누르면 풀려요.
- 숨긴 회원의 글, 숨긴 블로그의 글과 블로그는 **나에게만** 메인 피드·검색·블로그 목록에서 보이지 않아요.
- 상대에게는 알리지 않아요. 프로필이나 블로그에 직접 들어가면 그대로 보여요.
- 숨기면 그 회원 팔로우, 그 블로그 구독은 풀려요.

![프로필의 관심 없음 버튼](/img/releases/v1.13.0/profile-button.png)

**숨긴 것을 다시 보려면**

내 정보 화면 아래 **"관심 없음"** 칸에서 숨긴 회원·블로그를 보고 [풀기]를 누르면 돼요.

![내 정보의 관심 없음 목록](/img/releases/v1.13.0/me-list.png)

**차단과는 어떻게 다른가요**

차단은 서로의 글·댓글을 모두 숨기고 팔로우·댓글·좋아요를 막아요. 관심 없음은 내 피드와 검색에서만 가볍게 빼는 기능이에요.
