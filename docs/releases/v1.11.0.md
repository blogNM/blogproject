# Creat_ v1.11.0 업데이트 소식

코딩 블로그를 쓰는 분들을 위해 **코드 블럭**을 고쳤어요. 이제 코드 블럭에 바로 쓸 수 있고, 언어를 고르면 그 언어에 맞는 색이 입혀져요.

> 글쓰기에서 <span class="hl-yellow">[CB] 버튼</span>으로 코드 블럭을 넣고, 오른쪽 위 <u>언어 칸</u>을 눌러 Java·Python·JavaScript 같은 언어를 고르세요.

![이전에는 코드 블럭에 쓴 글자가 사라졌고, 이제는 입력되고 Java 색이 입혀져요](/img/releases/v1.11.0/editor-compare.png)

## 코드 블럭에 글자가 써지지 않았어요

**무엇이 불편했나요**

새 글에서 코드 블럭을 넣고 코드를 치면 글자가 보이지 않고 사라졌어요.

![고치기 전: 코드 블럭에 쳐도 안내 문구만 남는 모습](/img/releases/v1.11.0/editor-before.gif)

**원인**

빈 글에 코드 블럭만 있으면 "여기에 글을 쓰세요" 안내 문구가 코드 블럭 안으로 들어가, 치는 글자가 그 문구에 묻혔어요.

**어떻게 고쳤나요**

- 코드 블럭을 넣으면 그 아래에 빈 줄이 하나 생겨요. 안내 문구가 코드 블럭에 들어가지 않아 **바로 쓸 수 있어요**. 코드 블럭 밖으로 나가 이어 쓰기도 쉬워졌어요.

## 언어를 고르면 색이 입혀져요

- 코드 블럭 오른쪽 위 언어 칸에서 **24가지 언어**를 고를 수 있어요. Java, JavaScript, TypeScript, Python, C, C++, C#, Kotlin, Go, Rust, Swift, PHP, Ruby, Dart, R, SQL, HTML, CSS, JSON, YAML, Bash, Markdown, Diff, Text예요.
- 고른 언어에 맞춰 키워드·문자열·숫자·주석 색이 **쓰는 동안 바로** 바뀌어요.
- 글자는 개발 프로그램처럼 고정폭 글꼴이고, 탭은 4칸, 긴 줄은 가로로 넘겨 볼 수 있어요.
- 코드를 실행한 결과는 보여 주지 않아요.

![고친 뒤: 코드를 치고 Java를 고르면 색이 입혀지는 모습](/img/releases/v1.11.0/editor-after.gif)

## 글 화면에서도 같은 색으로

올린 글에서도 코드가 언어 색으로 보이고, 코드 블럭 오른쪽 위에 **언어 이름**이 붙어요. 공지사항 글도 같아요.

![이전에는 글 화면 코드가 한 가지 색, 이제는 언어 이름과 색이 함께 보여요](/img/releases/v1.11.0/post-compare.png)

## 운영 메모

| 항목 | 내용 |
|---|---|
| 입력 안 되던 문제 | `js/rich-editor.js` `codeBlockPlugin`: 문서가 코드 블럭 하나뿐이면 뒤에 빈 문단을 붙임 (ProseMirror `appendTransaction`) |
| 편집기 색 | `@toast-ui/editor-plugin-code-syntax-highlight` 3.1.0 + Prism 1.29.0을 `vendor/`에 둠 (CSP `script-src 'self'`). 언어 목록은 `CODE_LANGUAGES` |
| 글 화면 색 | `js/code-highlight.js`: 코드 블럭이 있는 글에서만 `vendor/prism/prism-creat.min.js`를 불러와 칠함 (`post.js`, `notice.js`) |
| 서버 거르기 | `MarkdownRenderer`: `pre` 바로 안 `code`의 `language-[a-z0-9+#-]{1,20}` class만 남김. 나머지 class는 지움 (SEC-06) |
