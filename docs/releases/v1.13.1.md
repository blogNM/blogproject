# Creat_ v1.13.1 업데이트 소식

**링크가 든 글**도 이제 저장 버튼을 누르면 바로 저장돼요.

> 저장하자마자 글을 열면 링크가 잠깐 <span class="hl-yellow">글자 링크</span>로 보일 수 있어요. 조금 뒤 다시 열면 미리보기 카드로 보여요.

## 링크가 든 글은 저장이 오래 걸렸어요

**무엇이 불편했나요**

글에 링크를 넣고 저장하면 저장 버튼이 몇 초씩 멈춰 있었어요. 링크가 많거나 링크한 사이트가 느리면 더 오래 걸렸어요.

**원인**

링크를 미리보기 카드(썸네일·제목·설명)로 보여 주려고, 서버가 저장할 때 그 자리에서 링크한 페이지와 썸네일을 받아 왔어요. 링크 하나에 3초까지, 최대 5개를 다 받은 뒤에야 "저장됐어요"라고 답했어요.

**어떻게 고쳤나요**

- 글은 바로 저장하고, 미리보기는 저장이 끝난 뒤에 따로 받아요.
- 받는 동안에는 링크가 원래 글자 링크로 보이고, 다 받으면 카드로 보여요.

**얼마나 달라졌나요**

> 링크 수 × 최대 3초를 기다림 → <span class="hl-yellow">링크가 없을 때처럼 바로 저장</span>.

## 운영 메모

| 항목 | 내용 |
|---|---|
| 바뀐 곳 | `PostController.collectPreviews` → `LinkPreviewService.collectAfterSave`가 `applicationTaskExecutor`에 맡김 |
| 설정 | `link-preview.background`(`LINK_PREVIEW_BACKGROUND`, 기본 true). false면 예전처럼 그 자리에서 받음. 테스트는 false |
| 서버가 꺼질 때 | 받는 중이던 미리보기만 빠지고 글은 그대로. 글을 다시 저장하면 다시 받음. 결과는 DB `link_previews`에만 둠 (SCL-01) |

- 테스트: `LinkPreviewTest.background` (저장 때는 바깥 사이트에 요청하지 않고, 맡긴 작업이 돌면 카드가 생김).
