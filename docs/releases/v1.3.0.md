# Creat_ v1.3.0 업데이트 소식

글쓰기 편집기가 쓰는 칸에 보이는 모양 그대로 글이 올라가는 편집기로 바뀌었어요.

## 바뀐 점

### 보이는 그대로 쓰는 글쓰기

- 글자 색·크기·형광펜·굵게를 주면 태그 대신 쓰는 칸에 바로 그 모양으로 보여요.
- 색·크기·형광펜을 먼저 고르고 쓰면 그 뒤로 쓰는 글자에 그대로 적용돼요. 이미 쓴 글자를 골라서 바꿔도 돼요.
- 글자 크기와 형광펜을 회원 글쓰기에서도 쓸 수 있어요.
- 글자 크기·형광펜 표시는 본문 1000자에 세지 않아요.

### HTML 보기

편집기 위 **HTML 보기**를 누르면 옆에 글의 HTML 구조가 보여요. 쓰는 대로 바로 바뀌고, 보기만 하는 창이라 HTML을 몰라도 걱정 없어요. **닫기**로 닫아요. 화면이 좁으면 편집기 아래에 열려요.

### 줄바꿈

글에서 엔터로 한 줄만 바꾼 곳이 이제 글 화면에서도 줄이 바뀌어 보여요. 예전 글도 똑같이 보여요.

## 관리자

- 관리자 **공지** 쓰기·고치기도 같은 보이는 그대로 편집기와 **HTML 보기**를 써요. 마크다운 글상자와 **미리보기**는 뺐어요. 사진은 그대로 공지 사진으로 올라가요.
- 편집기를 그리려고 관리자 화면(`/admin/index.html`)의 CSP에 인라인 style을 허용했어요. 스크립트 규칙은 그대로예요.

자세한 내용은 [D-106](docs/03-decisions/D-106-보이는-그대로-편집기.md)과 [CHANGELOG](CHANGELOG.md)에 있어요.
