# Creat_ v1.12.1 업데이트 소식

위쪽 내 사진 메뉴에서 **내 팔로워·팔로잉 수**를 바로 볼 수 있어요.

> 위쪽의 <span class="hl-yellow">내 사진을 누르면</span> 이름 아래에 팔로워와 팔로잉 수가 보여요.

![위쪽 사진 메뉴: 이름 아래 팔로워·팔로잉 수](/img/releases/v1.12.1/menu-follow.png)

## 팔로워·팔로잉 수가 메뉴에 보여요

**무엇이 불편했나요**

내 팔로워와 팔로잉 수를 보려면 내 활동 화면까지 들어가야 했어요.

**어떻게 고쳤나요**

- 사진 메뉴의 **"OO님" 아래**에 팔로워 수와 팔로잉 수를 보여 줘요.
- 숫자를 누르면 내 활동 화면의 **팔로워·팔로잉 목록**으로 바로 가요.
