# Creat_ v1.12.1 업데이트 소식

글 본문을 **공백 포함 3,000자**까지 쓸 수 있게 늘렸어요.

> 글쓰기 화면 아래에서 <span class="hl-yellow">공백 포함 글자 수와 공백 제외 글자 수</span>를 함께 볼 수 있어요.

![이전에는 1,000자까지였고, 이제는 3,000자까지 쓰면서 공백 제외 글자 수도 함께 보여요](/img/releases/v1.12.1/length-compare.png)

## 본문을 더 길게 쓸 수 있어요

**무엇이 바뀌었나요**

- 본문 최대 글자 수가 1,000자에서 **공백 포함 3,000자**로 늘었어요.
- 글쓰기 화면 아래에 "공백 포함 N / 3,000자 · 공백 제외 M자"가 함께 나와요.
- 사진은 지금처럼 글자 수에 넣지 않아요.

**왜 바꿨나요**

여행기나 후기처럼 긴 글을 쓰기에 1,000자는 너무 짧았어요.
