# Creat_ v1.7.1 업데이트 소식

로그인 화면의 **로봇 확인**을 단단하게 고쳤어요. 이제 진짜 Cloudflare 확인 상자가 로봇을 걸러 내고, <u>이메일을 바꿔 가며 틀리거나 관리자 화면에서 틀려도</u> 확인 상자가 나와요.

> 비밀번호를 여러 번 틀리면 <span class="hl-yellow">"사람인지 확인하세요" 상자</span>가 나와요. 상자를 누르고 다시 로그인하면 돼요.

![이전에는 이메일을 바꿔 5번 틀려도 아무것도 없었고, 이제는 로봇 확인 상자가 나와요](/img/releases/v1.7.1/member-compare.png)

## 로봇 확인 상자가 늘 통과됐어요

**무엇이 불편했나요**

로그인을 3번 틀리면 로봇 확인 상자가 나오긴 했지만, 누가 눌러도(로봇이 눌러도) 늘 통과됐어요.

**원인**

사이트가 Cloudflare가 연습용으로 주는 "늘 통과" 키로 돌고 있었어요.

**어떻게 고쳤나요**

- 진짜 키를 사이트 비밀 설정에서 받아 쓰도록 준비했어요. 키를 넣으면 그때부터 Cloudflare가 실제로 사람인지 확인해요.
- 연습용 키로 뜨면 서버 기록에 경고를 남겨서 빠뜨리지 않게 했어요.

## 여러 번 틀려도 확인 상자가 안 나왔어요

**무엇이 불편했나요**

- 이메일을 바꿔 가며 틀리면 몇 번을 틀려도 확인 상자가 나오지 않았어요.
- **관리자 로그인**은 몇 번을 틀려도 확인 상자도, 잠금도 없었어요.
- 확인 상자를 불러오지 못하면 빈칸만 생기고 왜 안 되는지 알 수 없었어요.

**원인**

틀린 횟수를 **이메일마다**만 셌고, 관리자 로그인은 아예 세지 않았어요.

**어떻게 고쳤나요**

- 이메일마다 세는 것에 더해, **같은 곳(IP)에서 1시간 안에 5번** 틀리면 이메일을 바꿔도 확인 상자가 나와요. 같은 곳에서 들어오는 다른 사람까지 막지 않도록 잠그지는 않아요.
- 관리자 로그인도 회원과 똑같이 **3번 틀리면 확인 상자, 5번이면 5분 잠금**이에요.
- 상자를 못 불러오면 "로봇 확인 상자를 불러오지 못했어요. 새로 고침하거나 광고 차단을 끄고 다시 해 주세요."라고 알려 줘요.

![관리자 로그인: 이전에는 5번 틀려도 그대로, 이제는 3번 틀리면 확인 상자](/img/releases/v1.7.1/admin-compare.png)

![관리자 로그인에서 3번 틀리고 확인 상자를 누른 뒤 로그인하는 모습](/img/releases/v1.7.1/admin-after.gif)

![확인 상자를 불러오지 못했을 때 나오는 안내](/img/releases/v1.7.1/load-failed.png)

**얼마나 달라졌나요**

> 이메일을 바꾸면 무한히 시도 → <span class="hl-yellow">같은 곳에서 5번이면 확인 상자</span>. 관리자 로그인은 무제한 → <u>3번 확인 상자, 5번 잠금.</u>

## 운영 메모

| 항목 | 내용 |
|---|---|
| 실제 키 | GitHub Actions secrets `TURNSTILE_SITE_KEY`·`TURNSTILE_SECRET_KEY` → `deploy.sh` → `secrets.env`. 만드는 법은 [도커-배포.md](docs/05-guides/도커-배포.md#로봇-확인-실제-키-넣기-d-114). 테스트 키면 시작할 때 `Turnstile 테스트 키를 씁니다` 경고 |
| 세는 곳 | `login_failures` 한 표: 회원 이메일 · `admin:아이디` · `ip:주소`. Flyway V17은 설명만 고침. `LoginGuard`가 회원·관리자 로그인에서 함께 씀 |
| 규칙 | 계정 3번 사람 확인·5번 5분 잠금(`LOGIN_CAPTCHA_AFTER`·`LOGIN_LOCK_AFTER`·`LOGIN_LOCK_DURATION`), IP 1시간 5번 사람 확인(`LOGIN_CAPTCHA_AFTER_IP`·`LOGIN_IP_WINDOW`). IP 수는 로그인 성공에도 지우지 않음, IP로는 잠그지 않음 |
| 화면 | `js/turnstile.js`(`createCaptcha`)를 `login.js`·`admin/login.js`가 같이 씀. 관리자 로그인 요청에 `turnstileToken` |

- 서버 메모리에 두지 않아 두 앱(8341·8342) 어느 쪽이 받아도 같은 수를 봄 (SCL-01, D-111).
- 캡처: 이 작업 환경에서는 Cloudflare에 닿지 않아, 확인 상자 자리에 모양만 비슷한 예시 상자를 띄우고 서버 확인 주소를 로컬 가짜 주소로 바꿔 찍었어요. 실제 사이트에서는 Cloudflare 상자가 나와요.
- 테스트: `LoginTest` 같은 IP 이메일 바꿔 5번, 관리자 3번 사람 확인·5번 잠금, 잠금 풀린 뒤 IP 사람 확인 유지.

자세한 내용은 [D-114](docs/03-decisions/D-114-로봇-확인-보완.md), [CHANGELOG](CHANGELOG.md)에 있어요.
