# Creat_ v1.12.0 업데이트 소식

코드 블럭을 개발 프로그램이나 메모 앱처럼 쓸 수 있게 **⋮ 메뉴**를 달았어요. 언어를 이름으로 골라 바로 색을 입히고, 코드 블럭을 한 번에 복사·삭제할 수 있어요.

> 글쓰기에서 코드 블럭 위에 마우스를 올리면 오른쪽 위에 <span class="hl-yellow">언어 이름 ⋮</span> 버튼이 보여요.

![이전에는 언어 이름을 직접 쳐서 골랐고, 이제는 ⋮ 메뉴에서 고르고 복사·삭제도 해요](/img/releases/v1.12.0/menu-compare.png)

## 무엇이 불편했나요

- 언어를 바꾸려면 오른쪽 위 작은 칸에 `java`, `cpp` 같은 이름을 직접 쳐야 했어요.
- 코드 블럭 하나를 통째로 복사하거나 지우려면 글자를 처음부터 끝까지 끌어서 골라야 했어요.

## 이렇게 바뀌었어요

코드 블럭 오른쪽 위 **언어 이름 ⋮** 버튼을 누르면 메뉴가 열려요.

- **복사**: 코드 글자만 그대로 복사해요.
- **잘라내기**: 복사하고 코드 블럭을 지워요.
- **삭제**: 코드 블럭을 지워요.
- **언어 ▸**: Java, Python, C, C++, C#, JavaScript, SQL 등 24가지 언어를 이름으로 골라요. 고르는 즉시 그 언어 색이 입혀져요. 맨 위 "일반 텍스트"는 색 없이 둬요.
- **기본 언어 ▸**: 자주 쓰는 언어를 골라 두면 **새로 넣는 코드 블럭에 그 언어가 바로 붙어요.** 이 브라우저에만 기억돼요.

## 코드 블럭에서 쉽게 나오고, 여러 개 넣기

- 코드 블럭 **마지막 줄에서 엔터를 두 번** 치면 코드 블럭 밖으로 나와 이어서 글을 쓸 수 있어요.
- 코드 블럭 안에서 **[CB] 버튼**을 누르면 바로 아래에 새 코드 블럭이 생겨요. 코드 블럭을 여러 개 이어 넣을 수 있어요.

![언어 ▸를 펼친 모습: 지금 고른 언어에 체크 표시](/img/releases/v1.12.0/menu-after.png)
