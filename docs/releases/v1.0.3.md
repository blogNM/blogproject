# Creat_ v1.0.3 업데이트 소식

사이트, 블로그, 글을 카톡이나 다른 사이트에 공유할 때 보이는 미리보기를 바꿨어요.

## 바뀐 점

### 사이트를 공유하면 로고와 사이트 색이 보여요

Creat_ 주소(https://creat.java21.net)를 공유하면 미리보기에 Creat_ 로고와 보라색 사이트 그림, 사이트 소개가 나와요.

![사이트 공유 미리보기 그림](/img/releases/v1.0.3/site-share.png)

### 블로그를 공유하면 배경과 이름이 보여요

블로그 주소를 공유하면 미리보기에 블로그 이름과 머리 사진이 나와요. 머리 사진을 아직 넣지 않았다면, 블로그 위쪽 배경(고른 테마와 강조 색)이 그대로 그림으로 나와요.

### 글을 공유하면 주소, 제목, 그림이 보여요

글 주소를 공유하면 미리보기에 글 제목과 그림, 주소가 나와요. 그림은 글에 넣은 첫 사진이고, 사진이 없는 글이면 블로그 머리 사진이나 배경이 대신 나와요.

비공개 블로그와 그 글은 지금처럼 미리보기에 아무것도 나오지 않아요.
