# Creat_ v1.15.1 업데이트 소식

눈에 보이는 화면은 그대로 두고, **계정과 사이트를 지키는 보안을 한층 더 단단하게** 했어요.

> 사이트 속도와 쓰던 기능은 그대로예요. 평소처럼 쓰시면 됩니다.

## 내 계정이 더 안전해졌어요

- **로그인 뒤 엉뚱한 사이트로 가지 않아요.** 로그인하면 원래 보던 화면으로 돌아가는데, 이 주소를 꾸며 다른 사이트로 보내는 방법을 막았어요.
- **비밀번호를 계속 맞혀 볼 수 없어요.** 비밀번호 변경이나 회원 탈퇴에서 지금 비밀번호를 1시간에 10번까지만 확인해요. 혹시 로그인 상태를 남에게 빼앗겨도 비밀번호를 알아내 계정을 가져가거나 탈퇴시킬 수 없어요.

## 사이트가 더 튼튼해졌어요

- **사진은 1분에 30장까지 올릴 수 있어요.** 글 하나에 10장이라 평소에는 걸리지 않고, 쉬지 않고 올려 서버를 채우는 것만 막아요.
- **쓰지 않는 브라우저 기능은 꺼 두었어요.** 카메라·마이크·위치 같은 기능을 Creat_에서는 아예 부를 수 없어요.
- **링크 미리보기가 안쪽 서버를 엿보지 못해요.** 글에 넣은 링크로 사이트 안쪽을 들여다보려는 우회 방법을 하나 더 막았어요.

**혹시 "너무 많이 시도했습니다"가 나오면?**

잠시 기다렸다가 다시 해 주세요. 비밀번호 확인은 1시간 뒤, 사진 올리기는 1분 뒤에 다시 돼요.
