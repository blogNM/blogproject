# Creat_ v1.10.0 업데이트 소식

Creat_에 **다크모드**가 생겼어요. 밤에 글을 읽거나 쓸 때 눈이 덜 부셔요.

> 위쪽 메뉴 검색 칸 옆의 <span class="hl-yellow">달 버튼</span>을 누르면 어두운 화면, <u>해 버튼</u>을 누르면 다시 밝은 화면이에요.

![이전에는 밝은 화면뿐이었고, 이제는 달 버튼으로 어두운 화면을 고를 수 있어요](/img/releases/v1.10.0/home-compare.png)

## 밝은 화면밖에 없었어요

**무엇이 불편했나요**

밤이나 어두운 곳에서 Creat_를 열면 화면 전체가 하얘서 눈이 부셨어요.

**원인**

화면 색이 밝은 색 한 벌뿐이었어요.

**어떻게 고쳤나요**

- 위쪽 메뉴에 **달·해 버튼**을 두었어요. 누르면 바로 바뀌어요.
- 고른 화면은 **이 브라우저에 기억**돼요. 다른 화면으로 가거나 다시 들어와도 그대로예요. 처음에는 밝은 화면이에요.
- 메인 피드, 검색, 글 화면, 내 정보, 내 블로그, 블로그 관리와 통계, 공지사항, 사용 방법, 오류 화면이 어두워져요.
- 글자와 버튼은 어두운 바탕에서도 잘 보이도록 밝은 보라색으로 바꿨어요.

![달 버튼을 눌러 다크모드를 켜는 모습](/img/releases/v1.10.0/dark-toggle.gif)

## 로그인 화면도 어둡게

다크모드에서는 **로그인·회원가입·비밀번호 찾기·이메일 찾기** 화면도 어두워져요. 오른쪽 미로 그림도 어두운 보라색으로 바뀌어요.

- **구글로 로그인**은 구글이 정한 어두운 버튼(검은 바탕, 회색 테두리)으로 바뀌어요.
- **네이버로 로그인**(녹색)과 **카카오로 로그인**(노랑)은 각 회사가 정한 색 그대로예요. 어두운 바탕에서도 잘 보여요.
- 로봇 확인 상자도 어두운 모양으로 나와요.

![밝은 화면과 다크모드의 로그인 화면](/img/releases/v1.10.0/login-dark.png)

블로그 홈은 블로그장이 고른 테마 색을 그대로 보여 주려고 밝게 두었어요. 글쓰기 화면과 관리자 화면도 밝은 화면 그대로예요.

## 운영 메모

| 항목 | 내용 |
|---|---|
| 켜고 끄기 | `js/layout.js` `modeToggle()`이 위쪽 메뉴에 버튼(`aria-pressed`, 달·해 SVG). 값은 `localStorage` `creat-color-mode`(dark/light), 서버에 보내지 않음 |
| 깜빡임 막기 | `js/color-mode.js`(보통 스크립트)를 `<head>`의 common.css 앞에서 읽어 `<html data-mode="dark">`·`data-mode-ready`. 인라인 스크립트는 CSP로 막혀 파일로 둠 |
| 색 | `css/dark.css`: common.css 색 변수 바꾸기 + 직접 쓴 색 고치기. 새 변수 `--field`·`--solid`·`--accent-text`·`--header-bg`. 로그인 카드도 어둡게, 구글 버튼은 가이드의 어두운 버튼, 미로 그림은 `filter: invert` |
| 적용 화면 | `dark.css`·`color-mode.js`를 읽는 20개 화면. `blog.html`(테마 틀)·`post-edit.html`(에디터)·`admin/*`은 읽지 않아 늘 밝고 버튼도 안 보임 |

- 서버 코드와 DB는 바뀌지 않음.
- 캡처: 로컬 테스트 데이터(D-113)로 찍음. "이전"은 main을 그대로 빌드해 같은 화면을 찍음.

자세한 내용은 [D-116](docs/03-decisions/D-116-다크모드.md), [CHANGELOG](CHANGELOG.md)에 있어요.
