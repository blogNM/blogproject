# Creat_ v1.2.0 업데이트 소식

Creat_를 어떻게 쓰는지 캡처와 함께 볼 수 있는 사용 방법 안내가 생겼고, 첫 화면과 로그인·가입 화면의 그림이 움직여요.

## 바뀐 점

### 메인 첫 화면의 기능 칸을 눌러 보세요

메인 첫 화면의 **테마 틀 7가지**, **함께 운영**, **댓글·좋아요·검색** 칸을 누르면 그 기능의 사용 방법이 열려요.

### 옆으로 넘겨 보는 사용 방법

사용 방법은 모두 6가지예요. 블로그 만들고 꾸미기, 함께 운영하기, 댓글·좋아요·검색, 블로그 골라 글 쓰기, 여러 블로그 한곳에서 보기, 팔로우·구독과 알림을 화면 캡처와 함께 설명해요.

- 휴대폰에서는 손가락으로 옆으로 밀면 다음 사용 방법으로 넘어가요.
- 컴퓨터에서는 마우스로 끌거나, 화살표·점을 누르거나, 키보드 ←/→로 넘겨요.
- 공지사항의 **일반** 탭에서도 같은 글을 볼 수 있어요. 아래쪽 **도움말**의 **사용 방법**으로도 들어갈 수 있어요.

![사용 방법 중 테마 틀 고르기 캡처](/img/guides/theme-new.png)

### 움직이는 그림

- 메인 첫 화면의 그림이 살아 움직여요. 글 카드와 말풍선이 둥실 떠오르고, 하트가 두근거리고, 별이 반짝여요.
- 로그인 화면에서는 보라색 관을 따라 빛이 흐르고 공이 통통 튀어요.
- 회원가입 화면은 새 그림이에요. 인증 메일을 실은 종이비행기가 날아가요.
- 기기에서 **동작 줄이기**를 켜 두면 그림은 움직이지 않아요.
