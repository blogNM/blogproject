# Creat_ v1.15.2 업데이트 소식

사이트 전체를 한 번 점검하고, 찾아낸 빈틈을 메웠어요. **계정은 더 안전하게, 사이트는 더 튼튼하게** 했어요.

> 쓰던 기능은 그대로예요. 평소처럼 쓰시면 됩니다.

## 내 계정이 더 안전해졌어요

- **인증번호를 마구 넣어 맞혀 볼 수 없어요.** 가입이나 비밀번호 찾기의 6자리 인증번호는 원래 5번 틀리면 무효가 돼요. 그런데 한꺼번에 아주 많이 보내면 이 제한을 넘을 수 있는 틈이 있었어요. 이제는 동시에 보내도 정확히 5번까지만 맞혀 볼 수 있어요.
- **비공개 블로그는 이름도 새지 않아요.** "관심 없음" 버튼으로 비공개 블로그가 있는지 알아보던 우회 방법을 막았어요.

## 사이트가 더 튼튼해졌어요

- **링크가 많은 글도 빨리 저장돼요.** 글에 넣은 링크의 미리보기 카드를 받을 때, 느린 사이트가 있어도 오래 기다리지 않아요. 늦은 링크는 다음에 글을 저장할 때 다시 받아요.
- **너무 큰 사진은 올릴 수 없어요.** 파일 크기는 작아도 가로·세로가 지나치게 큰 사진은 보는 사람의 브라우저를 멈추게 할 수 있어요. 5000만 화소(예: 10000×5000)까지 올릴 수 있어요.
- **좋아요·조회수가 정확해졌어요.** 좋아요를 빠르게 여러 번 눌러 숫자만 올라가거나, 글 속 사진 주소를 꾸며 조회수를 올리던 방법을 막았어요.
- **데이터를 더 잘 지켜요.** 사이트를 새로 올릴 때마다 데이터를 백업해 두어요.

**링크 미리보기 카드가 안 보인다면?**

미리보기는 보안 연결(https)이 되는 사이트에서만 받아요. 아주 오래된 http 전용 사이트는 카드 대신 글자 링크로 보여요. 링크는 그대로 눌러서 갈 수 있어요.
