# D-125 욕설 자동 거르기

- 날짜: 2026-10-15
- 관련 요구사항: 004 6.6 글 입력 규칙, US5 댓글, 001 닉네임 입력 규칙(USR-01, USR-07)
- 사용자 요청 (김채림, 2026-10-15): "욕설을 자동으로 필터링하는 기능이 있었으면 좋겟네"
- 고치기 전: 욕설을 막는 장치가 없었다. 신고(D-95)로만 처리했다
- 결정
  - 욕설 목록은 저장소에 둔다: `app/src/main/resources/profanity/words.txt`(한국어·영어), 욕이 아닌데 걸리는 말은 `allow.txt`. 목록을 고치면 배포로 반영한다
  - **글 제목·본문, 댓글**: 저장을 막지 않고 욕설을 글자 수만큼 `*`로 가려서 저장한다. 본문은 마크다운이라 `\*`로 넣어 굵게·기울임 표시로 읽히지 않게 한다. 본문 글자 수는 가리기 전 원문으로 센다
  - **닉네임, 글 태그**: 가리면 한글·영문·숫자 규칙에 어긋나므로 저장하지 않고 "욕설이 든 닉네임은 쓸 수 없습니다"(`PROFANE_NICKNAME`), "태그에 쓸 수 없는 말이 있습니다"(`PROFANE_TAG`)로 알린다. 가입·소셜 가입·내 정보 수정·닉네임 중복 확인 모두 같다
  - 찾는 방법: 대소문자를 가리지 않는다. 글자(한글·자모·영문) 사이에 낀 기호·숫자는 건너뛰고 찾는다(시1발, 시.발, s.h.i.t). 띄어쓰기를 넘어서는 찾지 않는다("하시 발표"가 걸리지 않게)
  - 링크·사진 주소(`https://…`, 마크다운 `](…)`)는 거르지 않는다. 주소가 바뀌면 링크와 사진이 깨진다
  - 이미 저장된 글·댓글·닉네임은 그대로 둔다. 고쳐서 다시 저장할 때 걸러진다
- 고르지 않은 것
  - 저장을 막기: 무엇이 걸렸는지 몰라 글을 다시 써야 하고, 긴 글을 잃을 수 있다
  - 보여 줄 때만 가리기: 검색·공유 미리보기(og)·알림 등 보여 주는 곳마다 따로 가려야 해서 빠지는 곳이 생긴다
  - 띄어쓴 욕설(시 발)까지 찾기: 두 낱말 사이에 걸리는 말이 너무 많다
  - 블로그 이름·소개, 프로필 소개: 요청 범위(글·댓글·닉네임) 밖이라 이번에는 넣지 않았다
