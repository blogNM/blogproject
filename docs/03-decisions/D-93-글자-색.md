# D-93 글쓰기의 글자 색

- 날짜: 2026-10-08
- 관련 요구사항: BRD-01, 헌법 III(XSS), CSP
- 선택지:
  1. 색을 자유롭게 고름 (본문에 `style="color:…"`을 남김)
  2. 정해 둔 색 몇 가지 중에서 고름 (본문에 `class="tc-색"`만 남김)
- 결정과 이유: 2번 (김채림 요청 "글 색깔도 바꿀 수 있도록", 방식은 Claude 추천, 2026-10-08).
  - 화면의 CSP가 style 속성을 막고 서버도 style을 지우므로, 색은 정해 둔 class로만 준다
  - 색 7가지: 빨강·주황·초록·파랑·보라·자주·회색. 툴바의 "A" 버튼, "색 빼기"로 되돌림
  - 서버는 `span`의 정해 둔 색 class만 남기고 다른 class·style은 지워 글자만 남긴다
  - 색 표시(`<span class="tc-…">`)는 본문 1000자에 넣지 않는다
- 이전 내용 → 바꾼 이유: 004에 없던 기능 추가
