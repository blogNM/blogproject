# D-92 글 속 링크를 미리보기 카드로

- 날짜: 2026-10-08
- 관련 요구사항: BRD-01, BRD-04, 헌법 III(XSS), CSP
- 선택지:
  1. 미리보기 카드: 썸네일·제목·설명을 담은 카드가 보이고, 누르면 그 사이트로 이동
  2. 카드 + 바로 재생: 유튜브 같은 정해 둔 사이트는 글 안에서 바로 재생 (CSP `frame-src`를 그 사이트들에 열어야 함)
- 결정과 이유: 1번 (김채림, 2026-10-08). 링크만 보이면 무슨 내용인지 들어가 봐야 알 수 있어서 카드로 보여 줌. 바로 재생은 하지 않음.
  - 링크 하나가 한 줄에 따로 있으면 카드로 바뀐다. 문장 안의 링크는 그대로 글자 링크
  - 제목·설명·썸네일은 글을 저장할 때 서버가 그 페이지의 og 태그를 한 번 받아 와 저장한다. 읽을 때마다 받지 않는다
  - 서버가 위험한 주소(내부망·localhost 등)로 요청하지 않게 막고, 받아 온 제목·설명은 글자로만 넣는다
  - 썸네일은 바깥 사진 주소를 그대로 쓰지 않고 서버가 받아 저장한 사진만 보여 준다 (CSP `img-src 'self'`, 독자 IP를 바깥에 넘기지 않음)
- 이전 내용 → 바꾼 이유: 004에 없던 기능 추가. 5단계를 마친 뒤 이어서 만든다
