# D-119 위쪽 메뉴의 내 프로필 사진과 로그인 화면 다크모드 버튼

- 날짜: 2026-10-15
- 관련 요구사항: SOC-03(프로필 사진), USR-07(내 정보), D-116(다크모드), D-113(테스트 표시), SEC-06
- 사용자 요청 (김채림, 2026-10-15): "로그인 화면에도 다크모드 할건지 안할건지 버튼을 오른쪽 끝에 아이콘으로 달아주고, 내 프로필을 이름 눌러서 들어가서 보는 거말고 메인 화면에서 이름과 함께 내 프로필 사진이 보이도록 하고 싶은데... 위에 검색창 있는 쪽에 하면 너무 정신없으려나? 그럼 회원이름을 빼고 프로필 사진이 낫나?"
- 선택지
  1. 오른쪽 끝에 사진만 두고, 누르면 이름·내 블로그·내 정보·로그아웃 메뉴가 열린다 (티스토리·velog·GitHub·유튜브 방식) → 고름
  2. "OO님" 글자 자리에 사진과 이름을 같이 두고 다른 링크는 그대로
  3. "OO님" 글자를 사진으로만 바꾸고 다른 링크는 그대로
- 결정
  - 로그인한 위쪽 메뉴는 **검색 · 알림 · 다크모드 · 내 사진** 네 개. "내 블로그 · 내 활동 · OO님 · 로그아웃" 글자 링크는 사진을 누르면 열리는 메뉴로 옮긴다
  - 메뉴 맨 위는 사진과 "OO님"(테스트 회원은 "테스트" 표시)이고, 누르면 내 활동(`/members/{id}`)으로 간다. 그 아래 내 블로그, 내 정보, 로그아웃
  - 사진이 없으면 닉네임 첫 글자를 보라색 동그라미에 보여 준다 (프로필 화면과 같음). `/api/me`가 `imageUrl`을 함께 준다
  - 메뉴 바깥을 누르거나 Esc를 누르면 닫힌다. 내 정보 화면에서 닉네임·사진을 바꾸면 위쪽 사진과 이름도 바로 바뀐다
  - 위쪽 메뉴가 없는 로그인·가입·소셜 가입 화면(`main.auth-page`)은 화면 오른쪽 위에 달·해 버튼을 둔다. 로그인 화면 HTML은 고치지 않고 `layout.js`에서 붙인다
  - 닉네임은 모두 `textContent`로 넣는다 (SEC-06)
