# D-107 네이버 로그인

- 날짜: 2026-10-13
- 관련 요구사항: USR-01, USR-03, USR-05, SEC-04, SCL-01, D-99, D-103
- 선택지:
  1. 네이버만 따로 컨트롤러·테이블을 만든다
  2. 구글 로그인(D-103)의 흐름·테이블(`social_accounts.provider`)을 그대로 쓰고, Spring Security OAuth2 Client에 `naver` 등록만 더한다
- 결정과 이유: 2번. 사용자 요청으로 구글 다음에 네이버 로그인을 넣는다 (2026-10-13). `social_accounts`는 처음부터 `provider` 칸이 있어 DB 변경(Flyway)은 없다.
  - 동작은 구글과 같다: ① 연결된 네이버 계정(`response.id`)이면 그 회원 ② 네이버 이메일과 같은 이메일의 회원이면 연결하고 로그인 ③ 처음 온 사람은 `/social-signup.html`에서 닉네임·필수 동의 3가지만 받아 가입. 탈퇴하면 연결을 지운다 (USR-05). 로그인 뒤에는 이메일 로그인과 같은 JWT 쿠키
  - 네이버는 스프링 기본 등록이 없어 직접 적는다: authorization `https://nid.naver.com/oauth2.0/authorize`, token `https://nid.naver.com/oauth2.0/token`, user-info `https://openapi.naver.com/v1/nid/me`, user-name-attribute `response`, `client_secret_post`, `authorization_code`, redirect `{baseUrl}/login/oauth2/code/{registrationId}`. scope는 쓰지 않는다(네이버는 개발자센터의 "제공 정보" 설정으로 정함)
  - 사용자 정보는 `{resultcode, message, response:{id, email, name, nickname, ...}}`라 `response` 안에서 id·email·name을 읽는다. 이름(name)은 이름 규칙에 맞을 때만 저장하고, 별명(nickname)은 쓰지 않는다(닉네임은 가입 화면에서 직접 정함)
  - 이메일은 꼭 있어야 한다. 사용자가 이메일 제공에 동의하지 않아 이메일이 없으면 가입·연결하지 않고 로그인 화면(`?social=no-email&provider=naver`)에 "네이버에서 이메일 제공에 동의해야 가입할 수 있어요."라고 알린다
  - 네이버는 이메일 확인 여부 값을 주지 않는다. 네이버 계정에 등록·확인된 연락 이메일이므로 구글의 email_verified와 같게 본다
  - 실패·거절 안내도 회사 이름을 붙여 보여 준다 (`?social=failed|unverified&provider=google|naver`)
  - 가입 화면 이메일 중복 확인(D-99)은 `provider`(google·naver·없음)를 더 알려 주고, 네이버가 연결된 이메일이면 "네이버 계정으로 가입된 이메일입니다. 로그인 화면에서 네이버로 로그인해 주세요."라고 안내한다. 예전 화면용 `google` 값은 그대로 둔다
  - 앱 값은 환경변수 `NAVER_CLIENT_ID`, `NAVER_CLIENT_SECRET`으로만 넣는다. 배포 워크플로는 깃허브 시크릿 이름을 정확히 몰라 `NAVER_CLIENT_ID || NAVER_ID || NV_CLIENT_ID`, `NAVER_CLIENT_SECRET || NAVER_SECRET || NV_CLIENT_PASSWORD || NAVER_CLIENT_PASSWORD` 순서로 읽는다. 비어 있으면 네이버 주소를 열지 않고 로그인 화면의 버튼도 숨긴다
  - 네이버 개발자센터 애플리케이션 설정: 서비스 URL `https://creat.java21.net`, Callback URL `https://creat.java21.net/login/oauth2/code/naver` (로컬 시험은 `http://localhost:8080`과 `http://localhost:8080/login/oauth2/code/naver`도 추가). 제공 정보는 이메일 주소 필수, 이름·별명은 선택
  - 버튼은 네이버 브랜드 가이드(권장 초록 버전)를 따른다: 배경 `#03A94D`, 로고·글자 `#FFFFFF`, 색은 바꾸지 않음(마우스를 올려도 그대로). 로고와 글자를 가운데로 모으고 사이를 8px 띄운다. 글자는 구글 버튼과 같은 꼴로 "네이버로 로그인". N 로고는 화면에 SVG로 직접 넣어 바깥 그림을 받지 않는다(CSP `'self'`). 크기·모서리는 구글 버튼과 같고 구글 버튼 바로 아래에 둔다
  - 카카오는 아직 넣지 않는다 → D-108로 넣음
- 이전 내용 → 바꾼 이유: D-103에서 "카카오·네이버는 아직 넣지 않는다" → 사용자 요청으로 네이버를 넣음
