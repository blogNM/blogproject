# D-100 공유 미리보기 그림

- 날짜: 2026-10-12
- 관련 요구사항: BLG-01, D-59, D-66, D-96
- 선택지: (사용자 요청이라 선택지 없음)
- 결정과 이유: 블로그를 공유하면 블로그 배경과 이름이, 글을 공유하면 주소·글 제목·그림이 미리보기에 나오게 한다 (김채림, 2026-10-12).
  - 블로그: og:title은 블로그 이름, og:image는 머리 사진. 머리 사진이 없으면 블로그 홈 머리 영역의 배경(테마 틀·강조 색 그라데이션)을 서버가 1200×630 PNG로 그린 `/blog/{주소}/og-image.png`
  - 글: og:title은 글 제목만(블로그 이름을 붙이지 않음), og:url은 글 주소, og:image는 글의 첫 사진 → 블로그 머리 사진 → 머리 배경 그림 순서. 그림이 늘 있으므로 twitter:card는 늘 `summary_large_image`
  - 머리 배경 그림에는 글자를 넣지 않는다 (서버 이미지에 한글 글꼴이 없음). 이름은 og:title로 함께 보인다
  - 비회원이 볼 수 없는 블로그는 그림도 404. 공유 링크(`?key=`)로 연 미리보기는 그림 주소에도 key를 붙인다
  - 그림은 요청마다 그려 서버 메모리에 두지 않는다 (SCL-01). 1시간 캐시
- 이전 내용 → 바꾼 이유: D-96은 머리 사진이 없으면 사이트 로고(`/img/og-default.png`)였고, 글은 사진이 없으면 그림이 빠졌음. 공유한 블로그·글이 어디 것인지 알아보기 쉽게 블로그 배경을 쓴다
