# D-116 다크모드

- 날짜: 2026-10-14
- 관련 요구사항: D-90(사이트 디자인), D-103·D-107·D-108(소셜 로그인 버튼), SEC-06, SCL-01
- 사용자 요청 (김채림, 2026-10-14): "다크모드 껐다키기 기능 → 다크모드가 적용되면 네이버 로그인 창을 요구사항에서 보여준데로 하얀색으로 구현하기"
- 사용자 요청 바뀜 (김채림, 2026-10-15): "로그인 부분도 다 검정으로 하자"
- 선택지
  1. 사이트에 다크모드를 새로 만들고 위쪽 메뉴에서 켜고 끈다. 로그인·가입 카드는 요구사항 화면대로 하얗게 둔다 → 처음에 고름, 2026-10-15에 아래 3번으로 바꿈
  2. 켜고 끄기 없이 기기가 다크모드여도 늘 밝은 화면으로 고정한다
  3. 1번과 같되 로그인·가입 카드도 어둡게 한다 → 고름 (2026-10-15)
- 결정
  - 위쪽 메뉴(검색 칸 옆)에 달·해 버튼. 누르면 바로 바뀌고, 고른 값은 그 브라우저(localStorage `creat-color-mode`)에만 남는다. 서버에는 보내지 않는다 (SCL-01). 처음에는 밝은 화면
  - `js/color-mode.js`(보통 스크립트, `<head>`)가 화면을 그리기 전에 `<html data-mode="dark">`를 붙여 밝은 화면이 깜빡이지 않는다. 인라인 스크립트는 CSP로 막혀 있어 파일로 둔다
  - `css/dark.css`가 common.css의 색 변수를 어두운 값으로 바꾸고, 색을 직접 쓰던 곳(입력 칸, 진한 버튼, 강조 글자, 경고 띠 등)만 따로 고친다
  - **로그인·가입·비밀번호 찾기·이메일 찾기 카드(`.auth-split`)도 다크모드에서 어둡다.** 오른쪽 미로 그림은 색을 뒤집어 어두운 보라로, 구슬과 별은 원래 색
  - 소셜 버튼은 각 회사 가이드를 따른다. 네이버(#03A94D, 흰 로고·글자)와 카카오(#FEE500)는 가이드 색을 어두운 바탕에서도 그대로 쓰고(어두운 버튼이 따로 없다), 구글은 구글 로그인 브랜드 가이드의 어두운 버튼(바탕 #131314, 테두리 #8E918F, 글자 #E3E3E3)
  - 사람 확인 상자(Turnstile)도 다크모드면 `theme: 'dark'`로 띄운다
  - 블로그 홈(블로그장이 고른 테마 틀, D-89), 글쓰기(Toast UI 에디터), 관리자 화면은 다크모드를 읽지 않아 늘 밝다
  - 브라우저가 페이지를 멋대로 어둡게 바꾸지 않도록 `color-scheme`을 밝은 화면은 `light`, 다크모드는 `dark`로 적는다
