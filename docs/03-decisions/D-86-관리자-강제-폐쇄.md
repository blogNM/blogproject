# D-86 메인 관리자의 블로그 강제 폐쇄도 7일 뒤 04:00, 철회는 블로그장

- 날짜: 2026-10-07
- 관련 요구사항: ADM-02, ADM-04, BLG-09, D-12, D-19
- 선택지:
  1. 관리자가 누르면 즉시 폐쇄
  2. 블로그장 폐쇄와 같이 누른 날짜 기준 7일 뒤 04:00 폐쇄
- 결정과 이유: 2번 (김채림, 2026-10-07). 폐쇄 버튼을 누른 날짜 기준 7일 뒤 새벽 4시에 폐쇄하고, 철회는 블로그장이 한다. 멤버가 자기 글을 챙길 시간을 주는 BLG-09와 같은 규칙이라 배치와 알림(즉시·3일 전·1일 전)을 그대로 쓴다.
