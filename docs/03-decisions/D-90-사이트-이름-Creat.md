# D-90 사이트 이름을 "Creat_"로, 화면 디자인을 새로 정함

- 날짜: 2026-10-08
- 관련 요구사항: 1장 개요, 7장 화면
- 선택지:
  1. "메인블로그"/"새 블로그" 그대로
  2. 새 이름 "Creat_"와 워드마크, 새 색·화면 틀
- 결정과 이유: 2번 (김채림 요청, 2026-10-08). 심플하지만 눈에 띄는 이름.
  - 워드마크: 보라→자주 그라데이션 글자 "Creat"와 복숭아색으로 깜빡이는 `_`
  - 색: 7C0CB4, 5720C3, DFB79F, 925B8F, 39385B, C39496. 배경은 따뜻한 흰색 #F4F1EE, 제목은 진한 남색, 버튼은 알약 모양
  - 화면 틀: 메인(왼쪽 큰 제목 + 오른쪽 그림), 로그인·회원가입(왼쪽 입력, 오른쪽 그림이 있는 카드), 오류(가운데 그림, "앗" 제목, 알약 버튼). 사용자가 보낸 참고 화면을 따름
  - 그림은 직접 그린 SVG, 글꼴은 Pretendard(OFL)를 서버에 둠. 바깥 CDN·저작권 있는 그림은 쓰지 않음
- 이전 내용 → 바꾼 이유: 화면·메일 제목의 "메인블로그" → "Creat_". 문서 속 "메인블로그"는 이 프로젝트(블로그 플랫폼)를 가리키는 말로 그대로 둠
