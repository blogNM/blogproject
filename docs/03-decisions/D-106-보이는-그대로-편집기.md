# D-106 보이는 그대로 쓰는 편집기와 HTML 보기

- 날짜: 2026-10-13
- 관련 요구사항: BRD-01, BRD-10, SEC-06, CSP, D-74, D-93, D-102
- 선택지:
  1. Toast UI Editor를 WYSIWYG(보이는 그대로)로 열어 회원 글쓰기와 관리자 공지 쓰기에 같이 쓴다. 저장은 지금처럼 마크다운 + 정해 둔 class의 `<span>`
  2. 지금 마크다운 칸을 두고 옆에 미리보기를 크게 둔다
  3. 직접 만든 contenteditable 편집기
- 결정과 이유: 1번. 사용자 요청 (김채림, 2026-10-13): "관리자 글쓰기에서 색은 글씨가 써졌을 때 적용되기, html 글씨 효과를 글 쓰는 회원이 바로 적용되는 걸 볼 수 있도록 하고, 블로그 관리자 창이든 블로그 이용자의 글쓰기든 html 구조는 따로 버튼을 누르면 옆에 창으로 보일 수 있도록". HTML을 모르는 회원도 쓰는 칸에서 바로 색·크기·형광펜을 보고 쓰게 한다. 이미 쓰던 Toast UI(D-74)가 WYSIWYG를 갖고 있어 새 파일을 들이지 않는다. 2번은 여전히 태그가 쓰는 칸에 보이고, 3번은 목록·표·붙여 넣기를 새로 만들어야 한다.
  - 공통 모듈 `js/rich-editor.js`. 회원 글쓰기(`/write`, `/blog/*/write`, `/blog/*/posts/*/edit`)와 관리자 공지 쓰기(관리자 화면 [공지] 탭)가 함께 쓴다. 공지의 글상자·미리보기 버튼은 없앤다(`POST /api/admin/notices/preview`는 그대로 둠)
  - 도구: 굵게·기울임·취소선, 글자 색 7가지(A), 형광펜 4가지(형), 글자 크기 3단계(가), 제목·구분선·인용, 목록·번호 목록, 사진·링크. 회원 글쓰기는 표·코드도. 회원 글쓰기에도 크기·형광펜이 생긴다(서버는 D-102부터 글 본문에서도 남기고 있었음)
  - 색·크기·형광펜은 글자를 고르면 그 글자에, 고르지 않으면 그 뒤로 쓰는 글자에 적용된다(한글 입력 포함). "색 빼기"·"보통 크기"·"형광펜 빼기"로 되돌린다. 버튼 밑줄·바탕이 지금 커서 자리의 서식을 보여 준다. 예전처럼 "글자"라는 자리 글을 넣지 않는다
  - 저장 형식은 바꾸지 않는다: 마크다운 + `<span class="tc-…">`·`ts-…`·`hl-…` 하나씩. 같은 글자에 여러 서식이면 `<span class="ts-large"><span class="hl-yellow">…</span></span>`처럼 겹쳐 감싼다. 편집기 안에서는 class를 합친 span 하나로 다루고(겹친 span을 읽을 때 편다), 정해 둔 class가 아닌 span·style은 편집 칸에서도 지운다
  - 굵게와 색을 같은 글자에 주면 `<span class="tc-red">**맛집**</span>이`처럼 굵게 표시를 span 안쪽에 둔다. `**<span …>맛집</span>**이`는 마크다운 규칙상 굵게가 되지 않기 때문이다
  - **HTML 보기**: 편집기 위의 [HTML 보기]를 누르면 오른쪽(좁은 화면은 아래)에 HTML 구조가 줄을 나누고 들여 써서 보인다. 쓰는 대로 바로 바뀌고, 읽기 전용이다(글자로만 넣음, SEC-06). [닫기]나 [HTML 닫기]로 닫는다. 글 화면에 실제로 나갈 모양(겹친 span, 줄바꿈 `<br>`)으로 보여 준다
  - **줄바꿈**: 편집기는 Enter 한 번을 마크다운 줄 하나로 적고, 편집 칸과 예전 미리보기도 줄을 바꿔 보여 줬다. 그런데 서버는 줄 하나 바꿈을 띄어쓰기로 보여 글 화면에서 줄이 붙었다. 서버가 줄 하나 바꿈을 `<br>`로 바꾸게 한다(MarkdownRenderer). 빈 줄로 나눈 문단은 그대로 문단이다. 지금 있는 글 중 줄 하나로 나눠 쓴 글도 쓴 사람이 미리보기에서 본 대로 줄이 바뀌어 보인다
  - 글자 수(1000자)에서 색과 같이 크기·형광펜 표시도 뺀다(PostRules, rules.js)
  - 번호 목록에서 Tab: 쓴 줄이면 다음 번호 줄, 빈 번호 줄이면 번호를 지운다(전과 같음)
  - CSP: Toast UI는 style 속성으로 화면을 그려 인라인 style을 허용해야 한다(D-74). 관리자 화면은 탭을 주소의 `#`로 고르는 한 페이지라 공지 탭만 고를 수 없어서, 글쓰기 화면처럼 `/admin/index.html`에만 `style-src 'unsafe-inline'`을 준다. 관리자만 열 수 있고, 스크립트 규칙(`script-src 'self'`)은 그대로다. Toast UI 파일은 관리자가 [공지] 탭을 열 때 불러온다
  - 회원·관리자 화면 변경이라 릴리스 노트에 넣을 수 있고, CHANGELOG에 남긴다
- 이전 내용 → 바꾼 이유: 회원 글쓰기는 마크다운 칸이라 색을 고르면 `<span class="tc-red">글자</span>`가 그대로 보였고, 관리자 공지도 마크다운 글상자 + 미리보기였음 → HTML을 모르는 사람도 쓰는 칸에서 바로 보이게 (사용자 요청)
