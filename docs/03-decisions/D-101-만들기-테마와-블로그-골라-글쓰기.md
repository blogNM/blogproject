# D-101 만들 때 테마 고르기, 블로그 골라 글쓰기

- 날짜: 2026-10-12
- 관련 요구사항: BLG-01, BRD-01, D-89
- 선택지: (사용자 요청이라 선택지 없음)
- 결정과 이유: 블로그를 만들 때부터 원하는 모양으로 만들고, 여러 블로그에 속한 회원이 한 곳에서 글을 쓰게 한다 (김채림, 2026-10-12).
  - 블로그 만들기 화면에서 테마 틀·강조 색·글꼴·머리 문구·머리 사진을 고른다. 고르는 방식과 검사는 블로그 관리의 테마 꾸미기(D-89)와 같고, `POST /api/blogs`의 `theme`(없어도 됨)으로 함께 보낸다. 값이 틀리면 블로그를 만들지 않는다
  - 메인 첫 화면의 [블로그 만들기]·[글 둘러보기] 옆에 [글 작성하기]. 만들었거나 참여한 블로그가 하나라도 있는 회원에게만 보인다
  - [글 작성하기]는 `/write`. 글쓰기 화면 위쪽에서 만들었거나 참여한 블로그(폐쇄 예정·폐쇄 블로그 빼고) 중 하나를 골라 그 블로그에 쓴다. 블로그를 바꾸면 카테고리·공지 칸이 그 블로그 것으로 바뀌고, 쓰던 글은 남는다. `/write?blog={주소}`로 처음 고를 블로그를 정할 수 있다
  - 블로그 안의 [글쓰기](`/blog/{주소}/write`)는 그대로
- 이전 내용 → 바꾼 이유: 테마는 블로그를 만든 뒤 블로그 관리에서만 고를 수 있었고, 글은 블로그에 들어가야만 쓸 수 있었음
