# D-120 코드 블럭 ⋮ 메뉴

- 날짜: 2026-10-15
- 관련 요구사항: BRD-01(글 작성), D-117(코드 블럭 언어별 색), D-106(보이는 그대로 쓰는 편집기)
- 사용자 요청 (김채림, 2026-10-15): "코딩 블럭은 이렇게 구현했으면 좋겠다는 거였어 이렇게 될까? 잘 쓰는 몇개의 언어들만이라도 괜찮아" (메모 앱 코드 블럭 캡처: 오른쪽 위 ⋮ → Copy · Cut · Delete · Language ▸ · Default code language ▸)
- 고치기 전 (D-117)
  - 코드 블럭 오른쪽 위 언어 칸을 누르면 입력 칸이 열려, 언어 이름(java, cpp …)을 치거나 소문자 목록에서 골랐다
  - 코드 블럭 하나를 통째로 복사·삭제하려면 글자를 끝까지 끌어 골라야 했다
- 결정
  - 글쓰기 편집기(`withCode`)의 코드 블럭에 마우스를 올리거나 커서가 들어가면 오른쪽 위에 "언어 이름 ⋮" 버튼이 뜬다. Toast UI(문법 강조 플러그인)의 언어 입력 칸은 숨긴다
  - 버튼 메뉴: **복사**(코드 글자만 클립보드로), **잘라내기**(복사 후 블럭 삭제), **삭제**, **언어 ▸**(고르면 바로 그 색), **기본 언어 ▸**(이제부터 새로 넣는 빈 코드 블럭에 붙는 언어)
  - 언어 목록은 D-117의 24개 그대로, 보이는 이름(Java, C++, C# …)으로 알파벳 순서. 맨 위 "일반 텍스트"는 언어 없음
  - 기본 언어는 이 브라우저(localStorage `creat.codeBlockLanguage`)에만 남긴다. 회원 정보에 저장하지 않으므로 서버·DB는 바뀌지 않는다. 저장소를 못 쓰면 기본 언어 없이 동작
  - 좁은 화면에서는 언어 목록이 옆이 아니라 메뉴 아래로 펼쳐진다. Esc나 바깥을 누르면 닫힌다
- 하지 않은 것
  - "Auto"(언어 자동 알아내기)는 넣지 않았다. 고른 언어만 칠한다
  - 글 화면(읽기)의 코드 복사 버튼은 이번 요청 범위가 아니어서 넣지 않았다
