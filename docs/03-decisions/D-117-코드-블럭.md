# D-117 코드 블럭 입력과 언어별 색

- 날짜: 2026-10-14
- 관련 요구사항: BRD-01(글 작성), D-74(Toast UI 에디터), D-110(편집기 도구), SEC-06(XSS), 헌법 III
- 사용자 요청 (김채림, 2026-10-14): "코딩 블로그를 쓰는 회원을 위해 → 코드 블럭 기능을 사용 → 어떤 언어를 사용하는지 정하면 그거에 맞춰서 색이랑 형식이 적용됨. 코드 블럭 기능이 있는데 정작 코드 블럭에 작성하려 하면 입력이 안되는 현상 해결해야함. 컴파일 결과는 안나와도 코드는 프로그램에서 작성해서 하는 형태로"
- 원인 (고치기 전)
  - 빈 글에서 [코드블럭]을 누르면 문서에 코드 블럭 하나만 남는다. Toast UI가 빈 문서에 띄우는 안내 문구("여기에 글을 쓰세요…")가 그 코드 블럭 안에 들어가, 치는 글자가 안내 문구에 묻혀 사라졌다
  - 언어 칸은 있었지만 색을 입히는 플러그인이 없어 무엇을 골라도 한 가지 색이었고, 서버가 `class="language-…"`를 걸러 내 글 화면에서도 언어가 남지 않았다
- 결정
  - 편집기: 문서가 코드 블럭 하나뿐이면 그 뒤에 빈 문단을 하나 붙여(ProseMirror `appendTransaction`) 안내 문구가 코드 블럭에 들어가지 않게 한다. 코드 블럭 밖으로 나가 이어 쓰기도 쉬워진다
  - 언어별 색: Toast UI 코드 문법 강조 플러그인(3.1.0) + Prism(1.29.0)을 서버에 두고 쓴다 (CSP `script-src 'self'`). 언어 목록은 java, javascript, typescript, python, c, cpp, csharp, kotlin, go, rust, swift, php, ruby, dart, r, sql, html, css, json, yaml, bash, markdown, diff, text 24개
  - 글 화면: 서버는 `pre` 바로 안의 `code`에만 `class="language-이름"`(영문 소문자·숫자·`+#-`, 20자까지)을 남기고 나머지 class는 지운다. 화면은 코드 블럭이 있는 글에서만 Prism을 불러와 칠하고 오른쪽 위에 언어 이름을 단다. Prism은 글자를 `span class="token …"`으로 감쌀 뿐 스크립트를 넣지 않는다
  - 코드는 고정폭 글꼴, 탭 4칸, 줄바꿈 없이 가로로 스크롤 — 개발 도구에서 쓰는 모양. 실행·컴파일 결과는 보여 주지 않는다 (요청대로)
  - 언어를 고르지 않은 코드 블럭은 지금처럼 한 가지 색이다
