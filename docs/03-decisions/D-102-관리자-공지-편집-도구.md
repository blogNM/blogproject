# D-102 관리자 공지 편집 도구

- 날짜: 2026-10-12
- 관련 요구사항: BRD-10, BRD-05, SEC-06, SEC-08, D-97, D-98
- 선택지: (사용자 요청이라 선택지 없음)
- 결정과 이유: 관리자가 공지를 편하게 꾸미도록 관리자 화면의 공지 쓰기·고치기에 서식 도구를 둔다 (김채림, 2026-10-12).
  - 도구: 굵게·기울임·취소선, 글자 크기(작게·크게·아주 크게), 글자 색 7가지, 형광펜 4가지(노랑·연두·분홍·하늘), 제목·목록·인용·구분선, 링크, 사진 넣기, 미리보기
  - 본문은 그대로 마크다운이다. 크기·색·형광펜은 정해 둔 class의 `<span>`(`ts-*`, `tc-*`, `hl-*`)으로 넣고, 서버가 그 class만 남긴다(나머지 span은 글자만). CSP가 style 속성을 막으므로 class로만 꾸민다. 글 본문에도 같은 규칙이 적용된다
  - 사진은 `POST /api/admin/notices/images`로 올린다. 검사는 회원 사진과 같다(SEC-08). 관리자는 회원이 아니므로 `images.uploader_id`를 비우고 `admin_uploader_id`에 올린 관리자를 남긴다(V11). 공지 사진은 글에 붙지 않으므로, 하루 지난 빈 사진을 지우는 정리 작업에서 뺀다
  - 미리보기는 `POST /api/admin/notices/preview`가 실제 공지와 같은 변환·거르기를 거친 HTML을 돌려준다
  - 관리자 화면 변경이라 회원용 릴리스 공지는 올리지 않고 CHANGELOG에만 남긴다 (김채림, 2026-10-12)
- 이전 내용 → 바꾼 이유: 공지는 마크다운 글상자뿐이라 꾸미기 어렵고, 사진은 릴리스 캡처(`/img/releases/`) 말고는 넣을 수 없었음
