# D-121 본문 최대 글자 수를 공백 포함 3,000자로

- 날짜: 2026-10-15
- 관련 요구사항: 004 6.6(글·댓글 규칙), 추천안 #14(글자 수 세는 기준), D-93·D-106·D-110(글자 수에서 빼는 표시)
- 사용자 요청 (김채림, 2026-10-15): "공백 포함: 2,500 ~ 3,000자 이상, 공백 제외: 1,500 ~ 2,000자 이상 으로 해줘. 글자수가 너무 적은것 같아"
- 고치기 전: 본문 최대 1000자(6.6 확정값). 블로그 글로는 원고지 5장 정도라 짧았다
- 결정
  - 본문 최대 글자 수는 **공백 포함 3,000자**. 블로그 글 권장 분량(공백 포함 2,500~3,000자, 공백 제외 1,500~2,000자)이 다 들어간다
  - 세는 기준은 그대로: 사진 문법, 글자 색·크기·형광펜 표시, 체크박스 표시는 빼고 센다 (추천안 #14, D-93, D-106, D-110). 공백·줄바꿈은 센다
  - 글쓰기 화면 아래에 "공백 포함 N / 3,000자 · 공백 제외 M자"를 함께 보여 준다. 최대 글자 수는 공백 포함 값으로만 본다
  - 서버(`PostRules.CONTENT_MAX`)와 화면(`rules.js` `POST_CONTENT_MAX`)이 같은 값을 쓴다. DB 칸(`TEXT`)은 그대로 넉넉하다
  - 사용 방법 "글 쓰기" 안내의 "본문은 1000자까지예요"는 마이그레이션 V19가 새 값으로 바꾼다
- 고르지 않은 것
  - 공백 제외 글자 수에 따로 최대를 두지 않았다. 공백 포함 3,000자면 공백 제외는 보통 2,000~2,300자라 요청한 범위를 넘는다
