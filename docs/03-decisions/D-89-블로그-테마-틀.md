# D-89 블로그마다 테마 틀 7가지 중 하나를 고르고 꾸밈

- 날짜: 2026-10-08
- 관련 요구사항: BLG-09(블로그 정보 수정), 004 화면, 헌법 III(XSS·CSP)
- 선택지:
  1. 모든 블로그가 같은 화면 (지금까지)
  2. 정해 둔 틀 몇 가지 중 고르고, 색·글꼴·머리 사진·문구만 바꿈
  3. 블로그장이 CSS·HTML을 직접 고침 (티스토리 "스킨 편집")
- 결정과 이유: 2번 (김채림 요청, 2026-10-08). 블로그마다 다르게 꾸미고 싶다는 요청. 3번은 CSS·HTML을 회원이 넣게 되어 XSS·CSP(`style-src 'self'`)를 지킬 수 없음.
  - 틀: Odyssey, Poster, Whatever, Letter, Book Club, Magazine, Portfolio (티스토리 스킨을 참고해 직접 만든 배치. 티스토리 코드는 쓰지 않음)
  - 고르는 것: 틀, 강조 색(`#RRGGBB`만), 글꼴(고딕·명조·고정폭), 머리 사진(블로그 대표 이미지 칸을 씀), 머리 큰 문구 40자·작은 문구 100자
  - 바꿀 수 있는 사람: 블로그장, "정보 수정" 권한이 있는 부블로그장 (BLG-13과 같음)
  - 저장 전 미리보기: `/blog/{주소}?preview=틀&accent=색…`. 권한이 있는 사람에게만 보이고 저장하지 않음
  - 색은 서버와 화면 둘 다 `#RRGGBB`로 확인하고, 화면은 CSSOM(`style.setProperty`)으로만 넣어 CSP를 그대로 지킴. 문구는 textContent
- 이전 내용 → 바꾼 이유: 블로그 화면이 하나뿐 → 사용자 요청으로 틀 7가지. DB에 `blogs.theme`, `theme_accent`, `theme_font`, `hero_title`, `hero_subtitle` 추가 (V3)
