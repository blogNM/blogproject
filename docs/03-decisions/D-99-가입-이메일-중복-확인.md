# D-99 가입 화면 이메일 중복 확인

- 날짜: 2026-10-12
- 관련 요구사항: USR-01, USR-02, D-28
- 선택지:
  1. D-28 유지: 화면 문구는 같게, 이미 가입된 이메일이면 메일로만 안내 (안내 문구만 추가했던 v1.0.1 초안)
  2. 가입 화면에 **중복 확인** 버튼을 두고 화면에서 바로 알려 준다
- 결정과 이유: 2번. 가입하는 사람이 메일함을 확인하기 전에 이미 가입된 이메일인지 바로 아는 편이 더 편하다 (김채림, 2026-10-12). 가입 화면에 한해 D-28을 바꾼다.
  - `GET /api/auth/signup/email-available?email=` → `{available}`. 닉네임 중복 확인과 같은 모양
  - 다른 사람 이메일을 하나씩 넣어 보는 것을 줄이려고 IP별 1분에 20번까지 (`RATE_EMAIL_CHECK_PER_MINUTE`)
  - 인증번호 요청도 이미 가입된 이메일이면 메일을 보내지 않고 409 `EMAIL_TAKEN`. "이미 가입된 이메일입니다" 안내 메일은 없앤다
  - 화면은 중복 확인을 통과한 이메일로만 [인증번호 받기]를 누를 수 있다. 이메일을 고치면 다시 확인해야 한다
  - 비밀번호 찾기·이메일 찾기는 그대로 가입 여부를 드러내지 않는다 (D-28, USR-06)
