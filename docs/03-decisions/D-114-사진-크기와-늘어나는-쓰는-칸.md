# D-114 사진 크기 조절과 글 따라 늘어나는 쓰는 칸

- 날짜: 2026-10-14
- 관련 요구사항: BRD-04(글 작성), SEC-08, D-64, D-106
- 사용자 요청 (김채림, 2026-10-14): "이미지나 gif 넣고 나중에 글 쓸 때 글자가 그림에 가려서 안 보이는 문제와, 올려야 되는 번거로움이 생기네. 이 문제를 해결해 주고, 이미지 크기를 크게 올릴지 작게 올릴지 스크롤? 인가 줌인 줌아웃 하는 느낌으로 크기 조절 되도록 해 주라"
- 원인: 글쓰기 칸 높이가 460px로 고정이었다. 큰 사진·GIF를 넣으면 칸이 사진으로 꽉 차서, 앞에 쓴 글은 칸 위로 밀려 가려지고 이어 쓰는 글은 칸 아래 끝에 겨우 보였다. 앞 글을 보려면 칸 안을 위로 올려야 했다. 사진 크기는 원래 크기 그대로라 줄일 방법이 없었다.

## 선택지

1. 쓰는 칸이 글·사진만큼 늘어나고(최소 460px), 도구 막대는 화면 위에 붙어 따라온다. 사진을 누르면 크기 막대가 뜨고, 사진 위에서 마우스 휠·두 손가락 확대/축소로도 크기를 바꾼다. 크기는 글 칸 너비의 10~100%(10% 단위)이고 사진 주소 끝에 `#w=60`처럼 남긴다
2. 쓰는 칸은 그대로 두고 편집 칸에서만 사진을 작게 보여 준다
3. 크기를 `<img width="…">` HTML로 저장한다

## 결정과 이유

1번.

- 2번은 편집 칸과 글 화면의 모양이 달라져 "보이는 그대로 쓰기"(D-106)와 맞지 않는다
- 3번은 jsoup 허용 목록에 `width` 속성을 더해야 하고, 편집기(Toast UI)가 마크다운으로 바꿀 때 HTML 사진을 그대로 지키지 못한다
- 1번은 마크다운 사진 문법(`![설명](/uploads/…#w=60)`)을 그대로 쓰므로 편집기·저장·글 화면이 같은 값을 본다. `#` 뒤는 브라우저가 서버로 보내지 않아 사진 받기에는 영향이 없다. CSP가 `style` 속성을 막으므로 크기는 CSS의 `img[src$="#w=60"]` 규칙으로 준다

## 정한 것

- 크기 값: 10·20·…·90(%)만. 100%(원래 크기, 글 칸보다 크면 글 칸 너비)는 표시를 붙이지 않는다
- 서버(`MarkdownRenderer.keepOnlyWidthMark`)는 사진 주소의 `#` 뒤가 `#w=10`~`#w=90`(10 단위)일 때만 남기고, 다른 값이나 다른 `#` 표시는 지운다
- 사진을 넣으면 바로 다음 줄(문단)로 내려가서, 이어 쓰는 글이 사진 옆에 붙지 않고 사진 아래에 쓰인다
- 크기 막대: [−] · 끌기 막대 · [+] · 지금 크기(%) · [원래 크기]. 사진 왼쪽 위 안쪽에 겹쳐 뜨고, 사진이 작으면 사진 위에 뜬다. 다른 곳을 누르면 사라진다
- 휠: 고른 사진 위에서만 크기를 바꾸고, 그 밖에서는 화면이 그대로 내려간다. 휠을 아래로 돌리면(두 손가락을 오므리면) 작게, 위로 돌리면(벌리면) 크게
- 사진 문법은 크기 표시가 붙어도 글자 수(1000자)에 넣지 않는다 (지금 규칙 그대로)
- 관리자 공지 편집기도 같은 편집기를 쓰므로 같은 기능이 생긴다
