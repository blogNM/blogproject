# D-95 제재 사유 항목

- 날짜: 2026-10-08
- 관련 요구사항: BLG-13, ADM-04, ADM-07, SOC-06, D-85
- 선택지: (사용자 요청이라 선택지 없음. 항목 목록은 Claude가 정한 기본값, 확인 대기)
- 결정과 이유: 신고를 처리하거나 멤버·블로그장을 제재할 때 제재 사유 항목을 하나 고르고, 처리한 신고와 제재 기록을 그 항목으로 나눠 본다 (김채림, 2026-10-08). 어떤 일로 제재가 많이 나가는지 한눈에 보려고.
  - 항목 8가지: 스팸·광고, 욕설·괴롭힘, 음란·불쾌한 내용, 개인정보 노출, 저작권 침해, 도배, 사칭, 기타. 신고 사유 6가지(SOC-06)에 도배·사칭을 더했다
  - 신고를 처리할 때 "문제 없음"이 아니면 꼭 고른다. 신고 사유와 같은 항목을 먼저 골라 둔다
  - 블로그 관리의 경고·정지·강제 퇴장과 관리자의 블로그장 경고도 꼭 고른다. 정지 풀기는 고르지 않는다
  - 제재받은 사람의 알림에 "사유: ○○"가 붙는다
  - 처리한 신고 목록에 항목별 건수와 거르기 단추, 제재 기록에 항목 거르기를 둔다. 이 결정 전에 처리한 제재는 "사유 없음"으로 센다
- 이전 내용 → 바꾼 이유: 6단계에서는 사유를 글로만 적었음. 사용자 요청으로 항목을 더함 (DB V8 `reports.sanction_reason`, `member_sanctions.reason_code`, `owner_warnings.reason_code`)
