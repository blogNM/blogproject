# D-85 신고 접수처: 블로그 안은 블로그장, 블로그장과 메인 프로필은 메인 관리자

- 날짜: 2026-10-07
- 관련 요구사항: SOC-06, ADM-04, BLG-13, D-45
- 선택지:
  1. 대상이 블로그 안에 있으면 모두 그 블로그의 블로그장이 처리 (블로그장 자신의 글·댓글 포함)
  2. 블로그장이 신고 대상이면 메인 관리자가 처리
- 결정과 이유: 2번 (김채림, 2026-10-07). 블로그장이 자기에 대한 신고를 스스로 처리하면 공정하지 않다.

| 신고 대상 | 처리하는 사람 |
|---|---|
| 블로그 안의 멤버, 멤버의 글·댓글 | 그 블로그의 블로그장 (멤버 관리 권한이 있는 부블로그장 포함) |
| 블로그장, 블로그장이 쓴 글·댓글 | 메인 관리자 |
| 블로그 자체 | 메인 관리자 |
| 메인 프로필에서 한 회원 신고 | 메인 관리자 |
