# D-122 "인기순" 기준

- 날짜: 2026-10-15
- 관련 요구사항: BLG-02(블로그 목록), BRD-08(통합 검색), BRD-09(메인 피드), 6.1 검색 정렬
- 사용자 확인 (김채림, 2026-10-15): 추천안대로 "좋아"
- 배경: 1편·2편·통합본 PDF 모두 "인기순"이라는 말만 있고 무엇으로 세는지는 없었다 (문서 오류가 아니라 빠진 내용)
- 선택지:
  1. 조회수 기준
  2. 좋아요 기준
  3. 블로그는 구독자 수, 글은 좋아요 수 (추천안 #6·#15)
- 결정과 이유: 3번.

| 화면 | 기준 |
|---|---|
| 블로그 목록·검색의 블로그 인기순 | 구독자 수 많은 순 |
| 메인 피드 인기 탭 | 최근 7일 안에 쓴 공개 글 중 좋아요 많은 순, 같으면 조회수 순 (기간은 설정값 `BOARD_POPULAR_WINDOW`, 기본 7d) |
| 검색의 글 인기순 | 좋아요 많은 순, 같으면 최근 글 |

  - 구독자 수는 블로그를 따라가는 사람 수라 블로그 인기를 가장 잘 보여주고, 숫자 하나로 정렬돼 응답 목표(D-48)를 지킨다.
  - 피드를 7일로 자르지 않으면 오래된 글이 위에 계속 남는다.
  - 조회수는 새로고침·봇의 영향을 받기 쉬워(D-77) 같은 좋아요 수일 때만 쓴다.
- 구현: 이미 이 기준으로 동작 중이다 (`BlogQueryService`, `FeedService`, `SearchService`). 이 기록은 그 기준을 확정한다.
