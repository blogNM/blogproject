# D-123 관심 없음: 회원·블로그를 나에게만 숨기기

- 날짜: 2026-10-15
- 관련 요구사항: 003 SOC-08(새로 만듦), SOC-05 차단(D-36), 004 SC-005(피드·검색에서 빼는 글)
- 사용자 요청 (김채림, 2026-10-15): "관심없는 블로그 또는 회원이 안뜨도록 각 사용자마다 필터링 기능" → "관심없음으로 해줘"
- 고치기 전: 보고 싶지 않은 회원을 빼는 방법은 차단뿐이었다. 차단은 양쪽 모두에게 글·댓글을 숨기고 서로 팔로우·댓글·좋아요를 막아서 무겁고, 블로그는 숨길 방법이 없었다
- 결정
  - 회원 프로필과 블로그 홈에 **관심 없음** 버튼을 둔다. 누르면 숨기고, 한 번 더 누르면 푼다
  - 메인 피드와 통합 검색의 글 카드 오른쪽 위에 **⋮ 메뉴**를 둔다(로그인했을 때만). "이 회원 관심 없음 (닉네임)", "이 블로그 관심 없음 (블로그 이름)"을 고르면 바로 숨기고, 지금 목록에서 그 회원·블로그의 글을 모두 뺀다. 내 글에는 회원 항목이 없다 (김채림 요청: 피드에서 바로 숨기기)
  - 숨긴 회원이 쓴 글, 숨긴 블로그의 글은 **나에게만** 메인 피드(모든 탭)와 통합 검색에서 빠진다. 숨긴 블로그는 블로그 목록과 블로그 검색에서도 빠진다
  - 상대에게 알리지 않고 상대 화면도 바뀌지 않는다. 댓글·좋아요·참여 신청도 막지 않는다
  - 프로필이나 블로그 홈에 직접 들어가면 그대로 보인다. 블로그 안의 글 목록과 댓글도 그대로다
  - 숨기면 내가 한 팔로우(회원)나 구독(블로그)은 풀린다. 상대의 팔로우는 그대로다
  - 내가 참여한 블로그에는 버튼이 없다. 나 자신은 숨길 수 없다
  - 내 정보 화면의 "관심 없음" 칸에서 숨긴 회원·블로그를 보고 풀 수 있다
  - 누르는 횟수는 팔로우·구독·차단과 같이 회원당 1분에 30번까지 (추천안 #11)
  - DB: `member_mutes`, `blog_mutes` (V20). 회원·블로그가 지워지면 함께 지운다(ON DELETE CASCADE)
- 고르지 않은 것
  - 숨긴 회원의 댓글까지 숨기기: 댓글은 글을 읽으러 들어간 곳이라 대화가 끊겨 보이지 않게 그대로 둔다. 댓글까지 안 보이게 하려면 차단을 쓴다
  - 숨긴 회원이 운영하는 블로그까지 함께 숨기기: 그 블로그의 다른 멤버 글까지 사라지므로 블로그는 따로 숨긴다
