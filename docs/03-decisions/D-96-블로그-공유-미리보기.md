# D-96 블로그 공유 미리보기

- 날짜: 2026-10-12
- 관련 요구사항: BLG-01, D-66, D-59, D-70
- 선택지: (사용자 요청이라 선택지 없음)
- 결정과 이유: 블로그 주소(`/blog/{주소}`)를 카톡 등에 공유하면 미리보기에 블로그 이름과 로고가 보이게 한다 (김채림, 2026-10-12). 미리보기 봇은 JS를 실행하지 않으므로 글 상세처럼 서버가 og 태그를 채운다.
  - og:title은 블로그 이름, og:description은 블로그 소개(없으면 "○○ 블로그입니다.")
  - og:image는 블로그 대표 이미지(머리 사진). 없으면 사이트 로고 그림 `/img/og-default.png`(1200×630)
  - 로그인하지 않은 사람이 볼 수 없는 블로그(비공개, 공유 링크 없는 일부 공개, 폐쇄)는 og 태그를 채우지 않는다. 공유 링크(`?key=`)로 열면 채운다
- 이전 내용 → 바꾼 이유: D-66은 "글 상세 페이지의 og 태그만 서버가 채움"이었음. 블로그 홈도 서버가 채우도록 넓힘. 나머지 화면은 그대로 정적 HTML
