# D-105 움직이는 그림

- 날짜: 2026-10-13
- 관련 요구사항: SEC-06, D-104
- 선택지:
  1. 그림 파일(SVG) 안에 움직임을 넣고 지금처럼 `<img>`로 보여 준다
  2. 그림을 화면 HTML 안에 그대로 넣고, 움직임은 `common.css`가 준다
- 결정과 이유: 2번. 사용자 요청 (김채림, 2026-10-13): 메인 첫 화면과 로그인 화면의 그림이 움직여 심플하면서도 역동적으로 보이게 하고, 회원가입 화면은 로그인과 비슷한 느낌의 다른 그림으로 바꾼다. 사이트 CSP는 `style-src 'self'`라 SVG 파일 안의 `<style>`이 막힌다. HTML에 넣은 SVG는 사이트 CSS로 움직일 수 있고, "동작 줄이기"를 켠 사람에게는 움직임을 끌 수 있다.
  - 메인 첫 화면: 들어오거나 새로 고칠 때마다 블록 쌓기(A, 블록이 내려와 얹힘)와 종이비행기(B) 중 하나를 고른다(index.js). 전에 쓰던 노트북 그림은 뺀다
  - 로그인: 같은 바닥판 위의 미로. 입구에서 출구까지 보라색 길을 따라 빛이 흐르고 공이 굴러간다(공은 SVG animateMotion, 동작 줄이기면 login.js가 pauseAnimations로 멈춤). 처음 그림의 알약은 뺀다
  - 회원가입(이메일 가입·구글 가입 화면 모두): 로그인과 같은 바닥판·색으로, 인증 메일 종이비행기(B)가 점선을 따라 날고, 인증번호 점이 차례로 깜빡이고, 확인 공이 두근거린다
  - 후보 A 블록 쌓기, B 종이비행기, C 새싹 화분을 보여 드리고 사용자가 정함: A·B는 메인(번갈아), B는 가입, C는 알림이 없을 때
  - `<img>`로 보여 주는 작은 그림(404·에러 화면의 용수철 `lost.svg`: 바닥을 천천히 굴러다니며 통통 튀고 둥근 머리가 빨간 경고등처럼 깜빡임, 알림이 없을 때의 새싹 화분 `empty-sprout.svg`, 검색 결과가 없을 때의 돋보기 `empty-search.svg`·빈 상자 손전등 `empty-box.svg` 중 하나를 고름)은 CSS가 닿지 않아 SVG 애니메이션(animate)으로 움직인다. 동작 줄이기를 켜면 `<picture>`가 멈춘 그림(`*-still.svg`)을 고른다(`layout.js`의 `motionImage`)
  - 그림이 처음 보일 때 살짝 떠오르며 나타난다. 움직임은 transform·opacity·stroke-dashoffset만 써서 가볍게 한다
  - `prefers-reduced-motion: reduce`이면 모든 움직임을 끈다. 그림은 꾸밈이라 화면 읽기 프로그램에는 숨긴다(aria-hidden)
  - 그림 안에 style 속성을 쓰지 않는다(CSP). 움직임을 늦추는 값은 class(`d1`~`d5`)로 준다
  - 쓰지 않게 된 `img/hero-art.svg`, `img/login-art.svg`는 지운다
- 이전 내용 → 바꾼 이유 (보충): 404 그림은 멈춰 있었고 알림이 없을 때는 글자만 있었음 → 사용자 요청
- 이전 내용 → 바꾼 이유: 그림이 멈춰 있었고 로그인과 가입 화면이 같은 그림이었음 → 사용자 요청
