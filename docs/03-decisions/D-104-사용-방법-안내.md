# D-104 사용 방법 안내

- 날짜: 2026-10-13
- 관련 요구사항: BRD-10, BRD-05, SEC-06, D-97, D-98, D-101
- 선택지:
  1. 정적 도움말 화면에 설명을 직접 적는다
  2. 공지사항 일반 카테고리에 "사용 방법" 글을 올리고, 그 글들을 옆으로 넘겨 보는 화면을 따로 둔다
- 결정과 이유: 2번. 사용자 요청 (김채림, 2026-10-13): 메인 첫 화면의 기능 칸(테마 틀 7가지, 함께 운영, 댓글·좋아요·검색)을 누르면 공지사항 일반에 올린 사용 방법(캡처와 설명)을 보고, 옆으로 끌어서 다른 사용 방법으로 넘긴다. 공지로 두면 관리자가 관리자 화면에서 고칠 수 있고(D-102), 공지사항 목록에서도 찾을 수 있다.
  - 안내 글: 공지사항 일반(NOTICE) 중 제목이 `사용 방법 · `으로 시작하는 글. 순서는 공지 번호(id) 순서. 처음 여섯 개는 DB V13이 넣는다: ① 블로그 만들고 테마 틀로 꾸미기 ② 여럿이 함께 블로그 운영하기 ③ 댓글·좋아요·검색 ④ 블로그 골라 글 쓰기 ⑤ 여러 블로그 한곳에서 보기 ⑥ 팔로우·구독과 알림
  - V13은 가장 먼저 만든 관리자를 작성자로 넣는다. 관리자가 없는 DB(처음 설치)에서는 아무것도 넣지 않는다. 그때는 관리자가 공지로 직접 올리면 된다. 새 공지 알림은 보내지 않는다
  - 캡처는 `/img/guides/`에 두고 본문에 마크다운 그림으로 넣는다. 글·공지 본문 거르기가 이 경로의 그림을 남긴다 (`/uploads/`, `/img/releases/`와 같이, CSP img-src 'self')
  - `GET /api/notices/guides`: 안내 글의 번호·제목·본문 HTML(공지 상세와 같은 변환·거르기). 비회원도 본다
  - 넘겨 보는 화면 `/guides` (`/guides?n=2`는 두 번째, `/guides?id=공지번호`는 그 글부터). 휴대폰은 손가락으로 밀고(CSS scroll-snap), 컴퓨터는 마우스로 끌거나 화살표·점·키보드 ←/→로 넘긴다. 제목은 textContent, 본문만 서버가 거른 HTML을 innerHTML로 넣는다 (헌법 III)
  - 메인 기능 칸 세 개는 각각 `/guides?n=1`, `n=2`, `n=3`으로 간다. 안내 공지의 상세 화면에는 [다른 사용 방법 넘겨 보기], 아래쪽 도움말 링크에 [사용 방법]을 둔다
- 이전 내용 → 바꾼 이유: 메인 기능 칸은 누를 수 없는 소개 글이었고, 사이트 사용 방법을 볼 곳이 없었음 → 사용자 요청
