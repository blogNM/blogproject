# D-98 공지 카테고리

- 날짜: 2026-10-12
- 관련 요구사항: BRD-10, D-97
- 선택지: (사용자 요청이라 선택지 없음)
- 결정과 이유: 공지 목록에서 릴리스 노트가 무엇에 대한 글인지 알 수 있게 카테고리를 붙인다 (김채림, 2026-10-12).
  - 카테고리는 두 가지: **공지**(`NOTICE`, 기본값)와 **업데이트**(`UPDATE`)
  - 깃허브 릴리스로 올라오는 공지(D-97)는 항상 업데이트. 관리자가 [공지] 탭에서 쓸 때는 고를 수 있다
  - 공지사항 목록·본문, 메인 화면 공지 칸, 관리자 공지 목록에 배지로 보인다
  - DB V10: `notices.category`. 이미 올라간 릴리스 공지(제목이 `Creat_ v`로 시작)는 업데이트로 바꾼다
