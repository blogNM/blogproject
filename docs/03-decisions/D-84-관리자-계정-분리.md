# D-84 메인 관리자는 회원과 분리된 계정이고 블로그 활동을 하지 않음

- 날짜: 2026-10-07
- 관련 요구사항: SEC-09, 2장 권한 표, ADM-01, D-44
- 선택지:
  1. 회원 계정에 관리자 권한을 붙여, 관리자도 블로그를 만들고 글을 쓴다 (2장 권한 표의 "O")
  2. 관리자 계정을 회원과 따로 두고, 관리 업무만 한다 (SEC-09)
- 결정과 이유: 2번. 메인 관리자는 블로그 활동을 하지 않는다는 팀 결정(김채림, 2026-10-07)을 따른다. SEC-09와 같고, 메인 관리자는 멤버를 관리하지 않는다는 D-44와도 맞는다.
- 이전 내용 → 바꾼 이유: 2장 권한 표의 메인 관리자 칸이 SEC-09·D-44와 어긋나 있어 아래처럼 고친다.

| 기능 | 이전 | 바뀜 |
|---|---|---|
| 블로그 목록·검색, 공개 글 읽기 | O | O (그대로) |
| 블로그 생성, 참여 신청, 글 쓰기 | O | **X** |
| 팔로우·댓글·좋아요 | O | **X** |
| 참여 승인·멤버 강퇴 | O | **X** (블로그장이 함, D-44) |
| 글 삭제, 블로그 폐쇄, 블로그장 강퇴 | O | O (그대로) |
