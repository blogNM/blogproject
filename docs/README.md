## 장별 위치

- 1편 `01-requirements/요구사항분석서_1_기본요구사항.pdf`: 1 개요, 2 사용자 유형과 권한, 3 기능 요구사항, 4 비기능 요구사항, 5 메인과 개별 블로그의 범위, 7 구현 방식
- 2편 `02-policies/요구사항분석서_2_세부정책_결정기록.pdf`: 6 세부 정책 (검색, SNS 공유, 파일 업로드, 태그, 중복 규칙, 글·댓글, 회원·보안·운영 숫자), 8 결정 기록

2편은 세부 정책과 결정 기록이 한 파일에 같이 있어서 `02-policies/`에 두었습니다. 결정 기록을 따로 나누게 되면 `03-decisions/`로 옮깁니다.
