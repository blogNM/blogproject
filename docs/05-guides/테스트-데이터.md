# 테스트 데이터

2026-10-07 ERD 작업 때 만든 테스트 데이터(34개 표, 188행)를 지금 스키마에 맞게 옮긴 것입니다. 회원 10명이 블로그 5개를 만들고 참여한 상태를 한 번에 만들어, 계정마다 로그인해서 기능이 쓰인 모습을 볼 수 있습니다.

## 넣는 방법

```bash
scripts/test-data/load.sh
```

- 지금 DB를 `backups/blog-날짜.sql`로 먼저 백업한 뒤, **모든 데이터를 지우고** 테스트 데이터로 바꿉니다. 직접 가입해 둔 계정도 사라집니다.
- 되돌리기: `mysql -u blog -p blog < backups/blog-날짜.sql`
- DB 이름·계정이 다르면 `DB_NAME`, `DB_USER`, `DB_PASSWORD`, `DB_HOST`로 바꿉니다.
- 서버는 켜 둔 채로 넣어도 됩니다. 넣은 뒤 브라우저에서 다시 로그인하세요.

## 바꾼 점

- 이메일은 실제 메일이 가지 않도록 모두 `아이디@example.com`
- 비밀번호는 모두 `Test1234!`
- 인증번호, 로그인 토큰, 로그인 실패 기록, 배치 잠금 표는 넣지 않음

## 아직 화면에 안 보이는 것

댓글, 공감, 구독, 알림, 신고·제재 데이터도 들어 있지만 화면은 4~6단계에서 생깁니다. 글 목록의 조회·공감·댓글 수와 메인 목록의 구독 수에는 이미 반영됩니다. 관리 화면의 정지·강퇴 표시는 6단계에서 보입니다.
