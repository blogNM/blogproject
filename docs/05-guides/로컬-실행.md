# 내 컴퓨터에서 실행하고 테스트하기

## 준비물

| 항목 | 버전 | 확인 |
|---|---|---|
| Java (JDK) | 21 | `java -version` |
| MySQL | 8.0 이상 | `mysql --version` |

Gradle은 따로 설치하지 않아도 됩니다. 프로젝트의 `./gradlew`가 알아서 받습니다.

macOS라면 Homebrew로 설치할 수 있습니다.

```bash
brew install openjdk@21 mysql
brew services start mysql
```

## 1. 데이터베이스 만들기 (처음 한 번)

```bash
mysql -uroot <<'SQL'
CREATE DATABASE blog CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
CREATE DATABASE blog_test CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
CREATE USER 'blog'@'localhost' IDENTIFIED BY 'blog';
GRANT ALL ON blog.* TO 'blog'@'localhost';
GRANT ALL ON blog_test.* TO 'blog'@'localhost';
SQL
```

테이블은 서버가 처음 뜰 때 Flyway가 `src/main/resources/db/migration/`의 SQL로 만듭니다.

## 2. 서버 실행

```bash
./gradlew bootRun --args='--spring.profiles.active=local'
```

브라우저에서 http://localhost:8080 을 엽니다.

`local` 프로필은 메일을 실제로 보내지 않고 **서버 콘솔(터미널)에 찍습니다.** 가입할 때 인증번호는 터미널의 `[개발용 메일]` 부분에서 확인하세요.

### Gmail로 실제 메일 보내기

Google 계정에서 2단계 인증을 켜고 [앱 비밀번호](https://myaccount.google.com/apppasswords)를 만든 뒤:

```bash
MAIL_MODE=smtp MAIL_USERNAME=내계정@gmail.com MAIL_PASSWORD=앱비밀번호16자리 \
  ./gradlew bootRun --args='--spring.profiles.active=local'
```

## 3. 자동 테스트

```bash
./gradlew test
```

`blog_test` 데이터베이스를 비우고 다시 만든 뒤 테스트합니다. 결과는 `build/reports/tests/test/index.html`에서 볼 수 있습니다.

## 5. 2단계 직접 확인하기

계정 두 개(A, B)가 필요합니다. 하나는 일반 창, 하나는 시크릿 창에서 로그인하면 편합니다.

| # | 해 볼 것 | 기대 결과 |
|---|---|---|
| 1 | A: 메인 [블로그 만들기] → 주소 `camping`, 참여 방식 "승인제" | `/blog/camping`으로 이동, 내 역할 "블로그장" |
| 2 | 주소에 `admin`이나 `ab`, 이미 쓰는 주소 넣고 [확인] | 쓸 수 없다는 안내 |
| 3 | A: 공개 블로그를 3개 만든 뒤 4번째 | "공개·일부 공개 블로그는 3개까지" (비공개는 5개까지 됨) |
| 4 | B: 메인에서 검색 → 블로그 열기 → [참여 신청하기] | "참여 승인을 기다리는 중", B의 [내 블로그]에 "승인 기다리는 신청" |
| 5 | A: 블로그 [블로그 관리] → [승인] | 멤버 표에 B, 이메일·전화번호는 가려짐 |
| 6 | B: [내 블로그] | "참여한 블로그"에 보임 |
| 7 | B: 블로그에서 [블로그 나가기] → 다시 [참여 신청하기] | 바로 다시 신청됨 |
| 8 | A: 관리에서 [거절] → B가 다시 신청 | "○월 ○일부터 다시 신청할 수 있습니다" (7일) |
| 9 | A: 관리에서 공개 범위 "일부 공개" 저장 | 공유 링크가 보이고, 로그아웃한 창에서 그 링크로만 열림 |

| 11 | 로그인 화면 [비밀번호 찾기] → 인증번호 → 새 비밀번호 | 새 비밀번호로 로그인, 다른 창의 로그인은 풀림 |

|---|---|---|
| 1 | 로그인하지 않고 `/blog/foodie-seoul` | 공지 1개, 글 목록, 왼쪽에 카테고리. 제목에 마우스를 올리면 사진 |
| 2 | [카페] 카테고리, 글의 `#서울` 태그 누르기 | 그 카테고리·태그 글만 보임 |

| 4 | minsu.park: [글쓰기] → 본문에 `<script>alert(1)</script>` 넣고 저장 | 알림 창이 뜨지 않고 그 줄이 사라짐 |
| 5 | 글쓰기에서 사진 버튼 또는 끌어다 놓기로 사진 올리기 | 본문에 사진이 들어가고 저장 뒤 목록 미리보기에 보임 |
| 6 | 확장자만 `.jpg`로 바꾼 다른 파일 올리기 | "jpg·jpeg·png·gif·webp 사진만 올릴 수 있습니다" |
| 7 | 글쓰기 중 창을 닫았다가 다시 [글쓰기] | "자동 저장된 글이 있습니다. 불러올까요?" |
| 8 | chaerim.dev: 남의 글 열기 | [수정]·[삭제] 버튼이 없음. 자기 글([성수동 카페 세 곳])에는 있음 |
| 9 | soyeon.jung(부블로그장): 민수의 글 열기 | [삭제]만 보임. 누르면 "글을 정말 삭제하시겠습니까?" |

## 운영 서버에 꼭 넣을 환경변수

| 이름 | 설명 |
|---|---|
| `DB_URL`, `DB_USERNAME`, `DB_PASSWORD` | MySQL 접속 정보 |
| `JWT_SECRET` | 로그인 토큰 서명 키, 32바이트 이상 임의 값 |
| `CODE_HASH_SECRET` | 인증번호 해시 키, 임의 값 |
| `MAIL_USERNAME`, `MAIL_PASSWORD` | Gmail 계정과 앱 비밀번호 |
| `TURNSTILE_SITE_KEY`, `TURNSTILE_SECRET_KEY` | Cloudflare Turnstile 실제 키 |
| `APP_BASE_URL` | 메일 속 링크와 글 미리보기(og 태그)에 쓸 사이트 주소 |
| `UPLOAD_DIR` | 올린 사진을 둘 폴더. 기본 `./data/uploads`, 백업 대상 |
| `BLOG_LIMIT_PUBLIC` | 회원 한 명이 만들 수 있는 공개 블로그 수. 기본 3, 5까지 |
| `FORWARD_HEADERS_STRATEGY` | 프록시(nginx 등) 뒤에 두면 `native` (IP별 요청 제한이 실제 IP로 셈) |

나머지 숫자(만료 시간, 실패 횟수, 요청 제한)는 `application.yml`에 기본값이 있고 같은 방식으로 환경변수로 바꿀 수 있습니다.
