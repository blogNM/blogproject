# 내 컴퓨터에서 실행하고 테스트하기

## 준비물

| 항목 | 버전 | 확인 |
|---|---|---|
| Java (JDK) | 21 | `java -version` |
| MySQL | 8.0 이상 | `mysql --version` |

Gradle은 따로 설치하지 않아도 됩니다. 프로젝트의 `./gradlew`가 알아서 받습니다.

소스코드는 저장소의 `app/` 폴더에 있고, 문서는 `docs/`·`specs/`에 따로 있습니다. 아래 명령은 모두 `app/` 폴더 안에서 실행합니다 (`cd app`). `.env`와 사진 폴더 `data/uploads`도 `app/` 안에 둡니다.

macOS라면 Homebrew로 설치할 수 있습니다.

```bash
brew install openjdk@21 mysql
brew services start mysql
```

## 1. 데이터베이스 만들기 (처음 한 번)

```bash
mysql -uroot <<'SQL'
CREATE DATABASE blog CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
CREATE DATABASE blog_test CHARACTER SET utf8mb4 COLLATE utf8mb4_0900_ai_ci;
CREATE USER 'blog'@'localhost' IDENTIFIED BY 'blog';
GRANT ALL ON blog.* TO 'blog'@'localhost';
GRANT ALL ON blog_test.* TO 'blog'@'localhost';
SQL
```

테이블은 서버가 처음 뜰 때 Flyway가 `app/src/main/resources/db/migration/`의 SQL로 만듭니다.

## 2. 서버 실행

```bash
cd app
./gradlew bootRun --args='--spring.profiles.active=local'
```

브라우저에서 http://localhost:8080 을 엽니다.

`local` 프로필은 메일을 실제로 보내지 않고 **서버 콘솔(터미널)에 찍습니다.** 가입할 때 인증번호는 터미널의 `[개발용 메일]` 부분에서 확인하세요.

### Gmail로 실제 메일 보내기

Google 계정에서 2단계 인증을 켜고 [앱 비밀번호](https://myaccount.google.com/apppasswords)를 만든 뒤:

```bash
MAIL_MODE=smtp MAIL_USERNAME=내계정@gmail.com MAIL_PASSWORD=앱비밀번호16자리 \
  ./gradlew bootRun --args='--spring.profiles.active=local'
```

## 3. 자동 테스트

```bash
./gradlew test
```

`blog_test` 데이터베이스를 비우고 다시 만든 뒤 테스트합니다. 결과는 `app/build/reports/tests/test/index.html`에서 볼 수 있습니다.

## 9. 6단계 직접 확인하기

서버를 다시 켜면 DB 변경(V7)이 저절로 들어갑니다. 테스트 계정 비밀번호는 모두 `Test1234!`입니다.

**관리자 페이지 들어가기**

1. 주소창에 `http://localhost:8080/admin/login.html`
2. 테스트 데이터를 넣었다면 관리자 아이디 `admin_kim`(또는 `admin_lee`), 비밀번호 `Test1234!`
3. 처음 들어가면 비밀번호를 바꾸는 화면만 나옵니다. 새 비밀번호(영문·숫자·특수문자 8~15자)로 바꾸면 관리자 페이지가 열립니다.

테스트 데이터가 없는 DB라면 `.env`에 `ADMIN_INITIAL_LOGIN_ID`와 `ADMIN_INITIAL_PASSWORD`(임시 비밀번호)를 넣고 서버를 다시 켜면 첫 관리자가 만들어집니다. 관리자가 한 명이라도 있으면 이 값은 무시됩니다. 회원 로그인으로는 관리자 페이지에 들어갈 수 없고, 관리자 로그인으로는 글쓰기 같은 회원 기능을 쓸 수 없습니다.

| 5 | 블로그장 위임에서 멤버 고르고 [위임 요청] → 그 계정으로 블로그 화면 | 위쪽 띠에 [수락]·[거절]. 수락하면 블로그장이 바뀌고 전 블로그장은 멤버 |
| 6 | [블로그 폐쇄] → [폐쇄 철회] | 블로그 위에 "○월 ○일 04:00에 닫혀요" 띠, 멤버·구독자에게 알림. 철회하면 띠가 사라짐 |
| 7 | 관리자 페이지 → 블로그 → [숨기기] | 멤버가 아니면 그 블로그가 목록·검색에 안 나오고 주소로도 못 봄. 멤버는 "숨겨진 블로그" 띠. [숨김 풀기]로 되돌림 |
| 8 | 관리자 페이지 → 신고 → 블로그장 글 신고를 "블로그장 경고"로 세 번 | 세 번째에 가장 먼저 된 부블로그장이 블로그장이 됨 (없으면 7일 뒤 폐쇄 예정) |
| 9 | 관리자 페이지 → 회원 → 상세 → [전체 보기] | 가린 이름·이메일·전화번호가 보이고 활동 기록에 "개인정보 전체 보기"가 남음 |
| 10 | 관리자 페이지 → 글·댓글 → [삭제] → 상태 "삭제됨"에서 [되살리기] | 글이 사라졌다가 돌아옴. 활동 기록에 둘 다 남음 |
| 11 | 신고 처리에서 결과를 "경고"로 고름 | 제재 사유 칸이 나오고 신고 사유와 같은 항목이 골라져 있음. [처리 완료] 탭에서 사유별 건수 단추로 나눠 봄, 제재 기록도 사유로 거름 (D-95) |

## 10. 빠졌던 기능 확인하기

서버를 다시 켜면 DB 변경(V9)이 저절로 들어갑니다.

| # | 해 볼 것 | 기대 결과 |
|---|---|---|
| 1 | 관리자 페이지 → [공지]에서 제목·내용을 쓰고 [공지 올리기] | 회원 종에 "새 공지사항" 알림. 메인 오른쪽 공지 제목을 누르면 본문, [전체 보기]는 `/notices` |
| 2 | 구독자가 있는 블로그를 [블로그 관리]에서 비공개로 바꿈 | 멤버가 아닌 구독자에게 "비공개로 바뀌었습니다" 알림 |
| 3 | 로그인하고 25분 동안 아무것도 누르지 않음 | "로그인을 연장할까요?" 창. [연장하기]를 누르면 계속 로그인 |
| 4 | 블로그 태그(예: 국밥)로 통합 검색 → 블로그 탭 | 그 태그가 달린 블로그가 나옴 |
| 5 | 블로그 글의 작성자 이름 → 프로필 → [이 블로그에 신고] | 그 블로그 멤버면 블로그장 화면 신고에 뜸 |
| 6 | [블로그 만들기]에서 대표 이미지를 골라 만들기 | 블로그 머리에 그 사진 |
| 7 | [블로그 관리] → 블로그 알림 보관 → [블로그 알림 모두 지우기] | 이 블로그의 블로그 알림이 받은 사람 모두에게서 지워짐 |
| 8 | 블로그 목록에서 글을 열고 [목록] | 보던 목록으로 돌아감 |
| 9 | 휴대폰에서 글의 [공유] | 기기 공유 창이 뜸 (PC는 주소 복사) |

## 운영 서버에 꼭 넣을 환경변수

| 이름 | 설명 |
|---|---|
| `DB_URL`, `DB_USERNAME`, `DB_PASSWORD` | MySQL 접속 정보 |
| `JWT_SECRET` | 로그인 토큰 서명 키, 32바이트 이상 임의 값 |
| `CODE_HASH_SECRET` | 인증번호 해시 키, 임의 값 |
| `MAIL_USERNAME`, `MAIL_PASSWORD` | Gmail 계정과 앱 비밀번호 |
| `TURNSTILE_SITE_KEY`, `TURNSTILE_SECRET_KEY` | Cloudflare Turnstile 실제 키 |
| `APP_BASE_URL` | 메일 속 링크와 글 미리보기(og 태그)에 쓸 사이트 주소 |
| `UPLOAD_DIR` | 올린 사진을 둘 폴더. 기본 `./data/uploads`, 백업 대상 |
| `BLOG_LIMIT_PUBLIC` | 회원 한 명이 만들 수 있는 공개 블로그 수. 기본 3, 5까지 |
| `ADMIN_INITIAL_LOGIN_ID`, `ADMIN_INITIAL_PASSWORD` | 첫 관리자 아이디와 임시 비밀번호. 관리자가 하나도 없을 때만 쓰임, 첫 로그인에서 바꿔야 함 |
| `FORWARD_HEADERS_STRATEGY` | 프록시(nginx 등) 뒤에 두면 `native` (IP별 요청 제한이 실제 IP로 셈) |

4단계 숫자는 `BOARD_REACTIONS_PER_MINUTE`(좋아요 1분 30번), `BOARD_COMMENTS_PER_MINUTE`(댓글 1분 10개), `BOARD_POPULAR_WINDOW`(인기 글 기간 7d), `BOARD_RECENT_SEARCH_MAX`(최근 검색어 10개)입니다.

나머지 숫자(만료 시간, 실패 횟수, 요청 제한)는 `application.yml`에 기본값이 있고 같은 방식으로 환경변수로 바꿀 수 있습니다.
