# 도커로 서버에 배포하기

`main`에 `app/` 변경이 들어오면 GitHub Actions가 자동으로 아래를 합니다. Actions 탭 → **배포** → **Run workflow**로 직접 돌릴 수도 있습니다.

1. **테스트**: MySQL 8을 띄워 `./gradlew test`. 실패하면 배포하지 않습니다.
2. **이미지 만들기**: `./gradlew bootJar` → `app/Dockerfile`로 `creat-blog:latest` 이미지.
3. **서버로 보내기**: SSH로 이미지 파일과 [`app/deploy/deploy.sh`](../../app/deploy/deploy.sh)를 서버의 `~/creat-blog/incoming/`에 올립니다.
4. **서버에서 실행**: `deploy.sh`가 이미지를 읽고 컨테이너를 새로 띄운 뒤, 사이트가 열리는지 확인합니다. 90초 안에 안 열리면 로그를 보여 주고 바로 전 이미지로 되돌립니다.

설정 파일: [`.github/workflows/deploy.yml`](../../.github/workflows/deploy.yml)

## GitHub에 넣을 값

Settings → Secrets and variables → Actions

**Repository secrets** (값이 감춰짐)

| 이름 | 꼭 | 내용 |
|---|---|---|
| `SSH_ADDRESS`, `SSH_PORT`, `SSH_ID`, `SSH_PASSWORD` | 꼭 | 서버 접속 정보 |
| `DB_ADDRESS`, `DB_PORT`, `DB_NAME`, `DB_PASSWORD` | 꼭 | MySQL 접속 정보. `DB_ADDRESS`가 `localhost`이면 서버 자신의 MySQL로 바꿔 부릅니다 |
| `DB_USERNAME` | | DB 아이디. 없으면 `SSH_ID`를 씁니다. Crowfoot에서 받은 DB는 계정이 따로 있어서 꼭 넣습니다 |
| `MAIL_USERNAME`, `MAIL_PASSWORD` | | Gmail 계정과 앱 비밀번호. 없으면 메일을 보내지 않고 서버 로그에만 찍혀 가입 인증번호가 가지 않습니다 |
| `ADMIN_INITIAL_LOGIN_ID`, `ADMIN_INITIAL_PASSWORD` | | 첫 관리자. DB에 관리자가 없을 때만 쓰입니다 |
| `TURNSTILE_SITE_KEY`, `TURNSTILE_SECRET_KEY` | | 사람 확인 실제 키. 없으면 늘 통과하는 테스트 키 |

**Variables** (값이 보임)

| 이름 | 꼭 | 내용 |
|---|---|---|
| `APP_PORT` | | 컨테이너를 열 서버 포트. 없으면 `8340`(학교 서버에서 받은 8340~8349의 첫 번호). 컨테이너 안에서는 8080으로 이어집니다 |
| `APP_BASE_URL` | | 사이트 주소. 없으면 `http://SSH_ADDRESS:APP_PORT`. `https://`로 시작하면 로그인 쿠키에 Secure가 붙습니다 |

## 서버에 생기는 것 (`~/creat-blog`)

| 위치 | 내용 |
|---|---|
| `data/uploads/` | 올린 사진. 컨테이너를 바꿔도 남습니다. **백업 대상** |
| `secrets.env` | 로그인 토큰·인증번호 서명 키. 처음 배포할 때 서버에서 만들고 계속 씁니다. 지우면 모두 로그아웃됩니다 |
| `runtime.env` | 이번 배포의 DB·메일 설정. 배포할 때마다 새로 씁니다 |

두 env 파일은 이 계정만 읽을 수 있습니다(600).

## 서버에서 직접 볼 때

```bash
docker ps                         # creat-blog 가 Up 인지
docker logs --tail 100 creat-blog # 서버 로그 (메일 모드가 log면 인증번호도 여기)
docker restart creat-blog         # 다시 켜기
```

## 확인한 것 (2026-10-08)

개발 컨테이너에서 같은 이미지와 `deploy.sh`를 MySQL 8 컨테이너에 붙여 끝까지 돌려 봤습니다: 처음 배포(키 만들기·DB 테이블 만들기) → 사이트·공지 200 → 두 번째 배포에서 전 이미지가 `previous`로 남음. 실제 학교 서버와 GitHub Actions에서는 아직 돌려 보지 않았습니다.

## 주의

- 서버 계정이 `docker` 명령을 쓸 수 있어야 합니다 (docker 그룹). 안 되면 스크립트가 그렇게 알려 줍니다.
- 서버의 MySQL이 컨테이너에서 오는 접속(127.0.0.1이 아닌 도커 내부 주소)을 받아야 합니다. DB가 다른 서버에 있으면 상관없습니다.
- 공용 서버라 자바 메모리를 512MB로 묶었습니다 (`JAVA_OPTS`).
