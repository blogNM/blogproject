# 배포 계획 (진짜 홈페이지로 열기)

2026-10-08 대화에서 정리한 내용입니다. 지금 사이트는 개발자 맥북의 `localhost:8080`에서만 돌아가서, 다른 사람이나 휴대폰으로는 들어올 수 없고 맥북을 끄면 꺼집니다.

## 언제

**6단계(제재·관리자)까지 만든 뒤** 진짜 오픈합니다. 신고 처리와 관리자 화면이 없으면 문제가 생겨도 막을 방법이 없기 때문입니다. 그 전에 누군가에게 보여줄 때는 아래 "잠깐 보여주기"를 씁니다.

## 잠깐 보여주기

맥북에서 Cloudflare Tunnel(`cloudflared tunnel --url http://localhost:8080`)을 켜면 임시 https 주소가 생깁니다. 무료이고, 맥북을 끄거나 명령을 멈추면 같이 꺼집니다. 이때는 `APP_BASE_URL`을 그 임시 주소로 바꿔 띄워야 메일 링크와 글 미리보기가 맞습니다.

## 진짜 오픈에 필요한 것

| 무엇 | 예 | 대략 비용 |
|---|---|---|
| 서버 (Java 21 + MySQL 8) | AWS Lightsail, 네이버 클라우드, 오라클 클라우드 무료 등급, Railway·Render | 월 1~2만 원 (작은 것) |
| 도메인 | `creat.kr` 같은 주소 | 1년 1~3만 원 |
| HTTPS | Let's Encrypt 또는 Cloudflare | 무료 |
| 운영 설정 | [로컬 실행 안내](로컬-실행.md)의 "운영 서버에 꼭 넣을 환경변수" 표: `JWT_SECRET`, `CODE_HASH_SECRET`, Gmail 앱 비밀번호, Turnstile 실제 키, `APP_BASE_URL`, `UPLOAD_DIR` 등 | |

- 학교 서버에는 GitHub Actions가 도커 이미지로 올립니다: [도커-배포.md](도커-배포.md).
- 서버에는 저장소의 `app/` 폴더(또는 거기서 만든 jar 하나)만 올립니다. 문서(`docs/`·`specs/`)는 올리지 않습니다.
- HTTPS가 없으면 로그인 쿠키(Secure)가 동작하지 않으므로 꼭 붙입니다.
- 프록시(nginx·Cloudflare) 뒤에 두면 `FORWARD_HEADERS_STRATEGY=native`로 실제 IP를 셉니다.
- 사진 폴더(`UPLOAD_DIR`)와 DB는 백업 대상입니다. 서버를 여러 대로 늘리면 사진은 S3로 옮깁니다 (D-75).
- 오픈 전에 `bulk-data.py`로 대량 데이터 속도를 한 번 더 재고, 동시 접속 부하 테스트(k6 등, 가상 사용자 100~200명)를 한 번 합니다.
